## 3. Findings

- **Algorithmic correctness:** the canonical json_each JSON-aware
  membership idiom (Lote 10.6bis Part 2a P0-1; sprint contract §5.5
  R-S06-10) catches drift > 0 with zero false-positives — substring
  collisions structurally impossible. The `prop_json_each_semantics_not_like`
  property test pins this and would fail loudly if anyone regressed
  the impl back to `LIKE '%digest%'`.
- **Auto-fix gate dual-condition:** the `count ≤ 5 AND percent ≤ 0.01%`
  gate per Lote 10.6bis P0-6 fires correctly at boundary inputs (count=5
  fires / count=6 rejects; percent=0.0001 fires / percent=0.000_101
  rejects).
- **Audit fail-closed envelope:** reconcile emits `corelink.gc.reconcile.refcount_manual_review_required`
  BEFORE the `blob_meta.refcount` UPDATE; emit failure surfaces
  `ReconcileError::AuditEmissionFailed` and the refcount is preserved
  (production wiring rolls back the D1 batch).
- **Gap closure:** at the 0.5% drift magnitude (above SEV-2 threshold
  0.1%, below SEV-1 1%) the auto-fix gate refuses to fire and the
  manual-review path is selected — exactly the runbook escalation path
  expected by an SRE on-call following RB-FM-300.
