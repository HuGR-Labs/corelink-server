## 3. Findings

- **Defense-in-depth canonical**: the 4-camada bulkhead (PAT-RATE-LIMIT-001
  per sprint contract §4) holds end-to-end at host-side property test
  cumulative 79 prop tests across 5 crates @ 10k iter PR speed. Each
  camada is independently verifiable + composable: camada 0 global
  circuit (zero-cost short-circuit when Open) → camada 2 edge per-IP
  (zero-cost drop of adversarial IPs) → camada 1 ratelimit per-tenant
  (DO actor model serialisation) → camada 3 quota-CAS (atomic check
  hard-block at 100% per ADR-0020 FROZEN supersedes S-07 PROVISIONAL)
  → camada 4 abuse (4-feature weighted-sum heuristic; 3-arm decision
  Benign/Suspicious/Malicious).
- **INV-AVAIL-ISOLATION canonical**: `prop_tenant_isolation` runs
  per-WI at 10k iter on every per-WI prop suite (5 crates). Zero
  cross-tenant violations across cumulative 50k iter. Counter
  `corelink_ratelimit_cross_tenant_violation_total` +
  `corelink_abuse_cross_tenant_feature_leak_total` MUST = 0; non-zero
  fires `Rate_InvAvailIsolationViolation` SEV-1 immediately.
- **Abuse calibration Wilson 95% CI**: per Lote 10.8bis P0-E corrected,
  the calibration sample (n=50 benign + n=50 high-intensity abusive
  workloads) yields **0/50 FP (Wilson upper 0.071)** + **50/50 TP
  (Wilson lower 0.929)** — well above the sprint contract acceptance
  bound (FP ≤ 5% upper-bound + TP ≥ 80% lower-bound).
- **Multi-signal trip canonical** (R-S08-004 mitigation): the global
  circuit breaker requires 5xx_rate AND p99_latency to both breach
  before tripping. Single-signal observed = `Rate_GlobalCircuitSingleSignalAlarm`
  SEV-3 informational (does NOT trip). This prevents false-positive
  trips that would convert one regional rate spike into a region-wide
  outage.
- **RFC 9331 grammar conformance**: `prop_rate_headers` 23 tests pin
  `RateLimit` + `RateLimit-Policy` header grammar conformance. The
  5-arm canonical X-Rate-Limit-Type taxonomy
  (tenant_quota / per_ip / per_pat / over_quota / global_circuit_open)
  is structurally exhaustive per `XRateLimitTypeKind` non_exhaustive
  enum.
