## 1. Scenario Injected

**Synthetic RUSTSEC advisory injection** simulating a legitimate dependency
(`serde@1.0.X`) with maintainer credentials compromised and a malicious version
published to crates.io. Dependabot opens an auto-merge PR with the new version.

Simulation method (host-side, no real crates.io publish):
1. Added a synthetic `RUSTSEC-2026-9999` advisory entry to local
   `~/.cargo/advisory-db/` test fixture.
2. Bumped `serde` version in a test branch `Cargo.lock` to a version
   that matches the synthetic advisory's affected range.
3. Opened a draft PR simulating a Dependabot PR.
4. Ran CI validation chain locally via `cargo audit --deny warnings`.
