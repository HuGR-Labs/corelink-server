# ── CAA-360 audit (2026-06-13): secrets that FAIL OPEN / SILENT when absent ──
# These four were identified by the 2026-06-13 security audit (F8 / F9 / F18) as
# secrets that were either not in the launch-readiness gate at all, or present in
# the matrix but not required by the MVP allowlist.  All four make the system
# silently degrade (wrong-tenant CAS prefix, guessable GDPR pseudonyms, guessable
# PATs, unavailable fabric introspection) when unset.  They MUST be provisioned
# before launch.  See docs/security/2026-06-13-CAA-360-followups.md §CI mechanization.
#
# R2_TDK_HEX: 32-byte hex key for per-tenant CAS HMAC prefix (matrix row #143).
#   Absent → container falls back to raw-padded public prefix → co-mingling risk
#   + poisonable Action Cache.  `openssl rand -hex 32` → set on ALL 5 container envs.
R2_TDK_HEX
#
# ERASURE_SALT_KEY: HMAC-SHA256 key for DSR erasure pseudonymization (matrix row #152).
#   Absent in prod → deriveErasureSalt() now throws (fail-CLOSED fix) → every erasure
#   returns 500 (Svix retries, obligation stays alive) until set.
#   Provisioned on the signup-worker (not the main worker) — same topology as
#   CLERK_WEBHOOK_SECRET (#150).  `openssl rand -hex 32` → wrangler secret put
#   ERASURE_SALT_KEY --config apps/signup-worker/wrangler.toml (NO --env).
ERASURE_SALT_KEY
#
# FABRIC_INTROSPECT_AUTH_KEY: auth key for POST /internal/v1/auth/introspect
#   (matrix row #151).  Absent → route stays unmounted (404 for fabric).
#   `openssl rand -hex 32` → wrangler secret put FABRIC_INTROSPECT_AUTH_KEY --env prod.
FABRIC_INTROSPECT_AUTH_KEY
