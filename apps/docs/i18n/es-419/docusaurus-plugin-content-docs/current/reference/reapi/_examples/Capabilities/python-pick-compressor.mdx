# Python — pick a compressor at runtime

Negotiate the best mutually-supported compressor.

## Code

```python
import asyncio, os
from corelink import CoreLinkClient, Compressor

PREFER = [Compressor.ZSTD, Compressor.IDENTITY]

async def main() -> None:
    async with CoreLinkClient(
        endpoint="https://corelink-api.humangr.com",
        pat=os.environ["CORELINK_PAT"],
    ) as client:
        caps = await client.capabilities.get()
        server_set = set(caps.cache_capabilities.supported_compressors)
        chosen = next((c for c in PREFER if c in server_set), Compressor.IDENTITY)
        print(f"using {chosen.name}")
        client.set_default_compressor(chosen)

asyncio.run(main())
```

## Expected output

```text
using ZSTD
```
