# Node / TypeScript — watch health transitions

Poll the health endpoint on a short interval; log every state transition.

## Code

```ts
import { CoreLinkClient } from "@corelink/client";

const client = new CoreLinkClient({
  endpoint: "https://corelink-api.humangr.com",
  pat: process.env.CORELINK_PAT!,
});

let last = "UNKNOWN";
setInterval(async () => {
  try {
    const s = await client.health.check();
    if (s !== last) {
      console.log(`[${new Date().toISOString()}] ${last} → ${s}`);
      last = s;
    }
  } catch (err) {
    console.warn("probe failed:", (err as Error).message);
  }
}, 1000);
```

## Expected output

```text
[2026-05-14T22:01:14.000Z] UNKNOWN → SERVING
[2026-05-14T22:02:01.000Z] SERVING → NOT_SERVING
```

## Common errors

| Failure | Cause | Fix |
| --- | --- | --- |
| `probe failed: UNAVAILABLE` | Server transient | Probe loop keeps running; no action needed |
