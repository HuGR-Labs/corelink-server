# Go — `BatchReadBlobs`

Lea muchos blobs pequeños con la verificación del lado del cliente
activada por defecto. El servidor no tiene una ruta REAPI de lectura por
lotes, así que `BatchRead` emite un GET por cada digest y verifica cada
blob antes de devolverlo — es un envoltorio de conveniencia, no un único
round-trip.

## Requisitos previos

```bash
GOPROXY=https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct go get go.corelink.humangr.com/corelink-go@v0.1.0
```

- `CORELINK_PAT` exportada

## Código

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, err := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Instance: "default",
    })
    if err != nil {
        panic(err)
    }
    defer client.Close()

    digests := []corelink.Digest{
        {Hash: "bdd9ea4a8e6b...", SizeBytes: 5},
        {Hash: "71c8b65b8b7e...", SizeBytes: 4},
    }
    blobs, err := client.CAS().BatchRead(ctx, digests)
    if err != nil {
        panic(err)
    }
    for d, data := range blobs {
        fmt.Printf("OK %s (%d B)\n", d.Hash[:12], len(data))
    }
}
```

## Salida esperada

```text
OK bdd9ea4a8e6b (5 B)
OK 71c8b65b8b7e (4 B)
```

## Errores comunes

| Tipo de error | Causa |
| --- | --- |
| `*corelink.NotFoundError` | Digest no presente (o expulsado del caché). |
| `*corelink.DigestMismatchError` | La verificación del lado del cliente rechazó los bytes devueltos. |
