# Go — elegir una función de digest

No existe un endpoint `Capabilities` para negociar una función de
digest (vea [GetCapabilities](./go-get-capabilities.mdx)). Elija una de
forma explícita: `corelink.DigestBLAKE3` es el valor predeterminado del
CAS y la única función que acepta la superficie nativa `/v1/cas`; use
`corelink.DigestSHA256` solo cuando sepa que la instancia REAPI con la
que habla lo espera.

## Código

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Digest:   corelink.DigestBLAKE3,
    })
    defer client.Close()

    // Switch at runtime if a particular call needs SHA-256 instead.
    client.SetDigestFunction(corelink.DigestSHA256)
    fmt.Println("using SHA-256 for this call")

    _ = ctx
}
```

## Salida esperada

```text
using SHA-256 for this call
```

## Errores comunes

| Tipo de error | Causa |
| --- | --- |
| `*corelink.AuthError` | PAT expirado. |
