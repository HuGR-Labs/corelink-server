# Go — puerta de disponibilidad de Kubernetes

Conecte `Client.Health` a un manejador de sonda de disponibilidad
(readiness probe) de Kubernetes.

## Código

```go
package main

import (
    "context"
    "net/http"
    "os"
    "time"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
    })
    http.HandleFunc("/ready", func(w http.ResponseWriter, r *http.Request) {
        ctx, cancel := context.WithTimeout(r.Context(), 2*time.Second)
        defer cancel()
        status, err := client.Health(ctx)
        if err != nil || !status.OK {
            http.Error(w, "not ready", http.StatusServiceUnavailable)
            return
        }
        w.WriteHeader(http.StatusOK)
    })
    http.ListenAndServe(":8080", nil)
}
```

## Salida esperada

```text
$ curl -i http://localhost:8080/ready
HTTP/1.1 200 OK
```

## Errores comunes

| Estado HTTP | Causa | Solución |
| --- | --- | --- |
| `503` | Falló `Client.Health` en el backend | Dispare el reinicio del pod mediante la sonda de liveness |
