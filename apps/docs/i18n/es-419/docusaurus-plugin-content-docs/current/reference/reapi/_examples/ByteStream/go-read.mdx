# Go — `ByteStream.Read`

## Código

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Instance: "default",
    })
    defer client.Close()

    digest := corelink.Digest{Hash: "bdd9ea4a8e6b...", SizeBytes: 41943040}
    out, err := os.Create("/tmp/big.bin")
    if err != nil { panic(err) }
    defer out.Close()

    n, err := client.ByteStream().Read(ctx, digest, out)
    if err != nil { panic(err) }
    fmt.Printf("downloaded %d B\n", n)
}
```

## Salida esperada

```text
downloaded 41943040 B
```

## Errores comunes

| Tipo de error | Causa |
| --- | --- |
| `*corelink.NotFoundError` | El digest fue expulsado del caché o nunca se escribió. |
| `*corelink.DigestMismatchError` | La verificación del lado del cliente rechazó los bytes transferidos. |
