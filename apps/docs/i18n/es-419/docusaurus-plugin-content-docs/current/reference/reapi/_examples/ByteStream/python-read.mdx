# Python — `ByteStream.Read`

Stream a large blob from CAS. Client-verify default on — the SDK rehashes as bytes arrive and aborts on mismatch.

## Code

```python
import asyncio, os
from pathlib import Path
from corelink import CoreLinkClient

async def main() -> None:
    digest = "sha256:bdd9ea4a8e6b...:41943040"
    out = Path("/tmp/big.bin")
    async with CoreLinkClient(
        endpoint="https://acme-dev.corelink.dev",
        pat=os.environ["CORELINK_PAT"],
    ) as client:
        with out.open("wb") as f:
            async for chunk in client.bytestream.read(digest):
                f.write(chunk)
        print(f"downloaded {out.stat().st_size} B")

asyncio.run(main())
```

## Expected output

```text
downloaded 41943040 B
```

## Common errors

| Status | Error taxonomy | Cause |
| --- | --- | --- |
| `NOT_FOUND` | `COR_CAS_BLOB_MISSING` | Digest evicted or never written. |
| `ABORTED` | `COR_CAS_DIGEST_MISMATCH` | Client-verify rejected partial stream. |
