# `POST` `/v1/consent/{purpose}`

> Grant consent for one canonical purpose.

- **Operation ID:** `consentGrant`
- **Tag:** `privacy-consent`
- **Rate-limit class:** consent-default (60 req/min/tenant)

## Description

12 canonical purposes per `privacy_model.md §5.6.1`. Records 6-field
proof (`notice_text_hash`, `notice_version`, `locale`, `wording_id`,
`ui_capture_ts`, `submission_ts`) and HMAC-SHA256 signs with
tenant-scoped key (HKDF `corelink/v1/consent-hmac`).

- `BearerPAT`
