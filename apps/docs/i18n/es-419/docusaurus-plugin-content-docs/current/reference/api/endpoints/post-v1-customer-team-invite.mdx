# `POST` `/v1/customer/team/invite`

> Create a one-time cryptographic team invitation.

Requires `ClerkSessionCookie` or `BearerPAT`. The request contains `email` and
`role`; the 256-bit lower-case hex invitation token is returned exactly once.
Only its SHA-256 digest is stored.

| Status | Meaning |
| --- | --- |
| `201` | Invitation created; token shown once. |
| `401`/`403` | Authentication or authorization failure. |
| `500` | Server error. |
