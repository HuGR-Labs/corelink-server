# `POST` `/v1/customer/keys/{pat_id}/revoke`

> Revoke a Personal Access Token by id.

- **Operation ID:** `customerKeyRevoke`
- **Tag:** `pat`
- **Rate-limit class:** pat-issue (10 req/hour/tenant)

## Description

Revocation is a destructive tenant-admin operation. It requires the
server-trusted `owner` or `admin` team role from a Clerk dashboard
session; cache-write scope alone is not sufficient. An owner may
revoke any PAT in the tenant. An admin may revoke member PATs but is
rejected with `403` for the owner's PAT. Members, viewers, native PAT
callers, and cross-tenant targets are rejected (the latter as `404`).
Subsequent uses of the revoked token MUST fail closed
(`INV-PAT-REVOKE-PROPAGATION`).
