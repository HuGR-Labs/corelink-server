## Inputs the calculator uses

| Input | Default | Notes |
| --- | --- | --- |
| Average storage (GB-month) | 100 | Hot tier only; cold-tier overflow priced separately. |
| Monthly cache hits | 1,000,000 | Hits are free; volume informs which tier fits best. |
| Cache hit ratio | 0.85 | Used to derive expected origin pulls. |
| Cross-region egress (GB / month) | 50 | Egress within a single region is not billed. |
| Plan | Pro | Sets base fee and included quotas. |
