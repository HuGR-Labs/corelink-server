# Solución de problemas

## Cuándo usar esta guía

Una llamada de `@corelink/client` está lanzando una excepción o quedándose colgada. Todo error
extiende `CoreLinkError` y lleva un `status` (estado HTTP, cuando se origina en el servidor)
y un `code` corto (la cadena de motivo del servidor). Inspecciónelos:

## Flujo de diagnóstico

```typescript
import { CoreLinkError } from "@corelink/client";

try {
  await client.get(digest);
} catch (e) {
  if (e instanceof CoreLinkError) {
    console.error(`${e.name} status=${e.status} code=${e.code}: ${e.message}`);
  }
  throw e;
}
```

## Errores comunes

Asigne la clase lanzada a su causa y solución:

| Clase | Estado | Primera acción |
|---|---|---|
| `AuthError` | 401 | Vuelva a exportar `CORELINK_PAT`; si está revocado, genere un PAT nuevo. |
| `ForbiddenError` | 403 | Tenant incorrecto, o el PAT carece del alcance de caché requerido. |
| `QuotaError` | 402 | Tenant por encima de su límite de almacenamiento / techo de gasto. |
| `NotFoundError` / `ActionCacheMiss` | 404 | Digest / action no almacenado para este tenant. |
| `GoneError` | 410 | El artefacto fue borrado (GDPR/DSR); no regresará. |
| `DigestMismatchError` | 422 / verify | Descarte los bytes; vuelva a descargar o a subir. |
| `RateLimitError` | 429 | Se reintenta automáticamente; si sigue apareciendo, baje la concurrencia. |
| `ServerError` | 5xx | Falla transitoria del backend; reintente con retroceso. |
| `ConnectError` | — | Falla de transporte; revise la red / `baseUrl`. |

## Sin paso de compilación nativa ni WASM

`@corelink/client` es JavaScript puro (BLAKE3 vía `@noble/hashes`). No hay artefacto
`.wasm` que empaquetar ni regla de asset de bundler que configurar — si encuentra un
error de resolución, es un problema común de resolución de paquete ESM, no de WASM.

## Ciclo de vida

`close()` hoy es una operación sin efecto (el SDK usa el `fetch` de la plataforma y no mantiene
un pool persistente), pero llámelo de todos modos para que su código siga siendo correcto si una
versión futura agrega pooling:

```typescript
const client = new CoreLinkClient({ tenantId: "acme-corp" });
try {
  await client.get(digest);
} finally {
  await client.close();
}
```

## Registro detallado

```bash
export CORELINK_LOG=debug
```

Los registros JSON estructurados van a `stderr`. Canalícelos con `jq`:

```bash
node ./script.mjs 2>&1 | jq 'select(.level=="error")'
```

## Cómo reportar un error

Incluya la salida de `corelink doctor --json`. Nunca incluya su PAT.
