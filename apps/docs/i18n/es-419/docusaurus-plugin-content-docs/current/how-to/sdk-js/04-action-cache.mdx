# Búsqueda y almacenamiento en Action Cache

## Cuándo usar esta guía

Usted envuelve un ejecutor de pruebas basado en JS (por ejemplo, Jest, Vitest, Playwright) con una
capa de caché de compilación y quiere semántica de acierto/fallo indexada por un digest de Action.

Si solo necesita el CAS sin procesar, consulte
[02-upload-blob](./02-upload-blob.mdx) y
[03-download-blob](./03-download-blob.mdx).

## El payload del AC son bytes opacos

CoreLink almacena un **payload de bytes `ActionResult` opaco** indexado por un digest de
action de 64 hex (`routes/ac.rs`). El SDK mueve esos bytes literalmente — usted es dueño de la
codificación (por ejemplo, un mensaje `ActionResult` de REAPI serializado, o su propio manifiesto
JSON que referencia blobs del CAS por digest). `actionCache.get` devuelve un
`Uint8Array`; `actionCache.put` recibe uno.

## Búsqueda

```typescript
import { ActionCacheMiss } from "@corelink/client";

async function getOrRun(actionDigest: string): Promise<Uint8Array> {
  try {
    const resultBytes = await client.actionCache.get(actionDigest);
    const manifest = JSON.parse(new TextDecoder().decode(resultBytes));
    return client.get(manifest.stdoutDigest); // fetch the referenced CAS blob
  } catch (e) {
    if (e instanceof ActionCacheMiss) {
      return runLocallyAndStore(actionDigest);
    }
    throw e;
  }
}
```

## Almacenamiento

```typescript
async function storeResult(
  actionDigest: string,
  stdout: Uint8Array,
  exitCode: number,
): Promise<void> {
  const stdoutDigest = await client.put(stdout);
  const manifest = { stdoutDigest, exitCode };
  const bytes = new TextEncoder().encode(JSON.stringify(manifest));
  await client.actionCache.put(actionDigest, bytes);
}
```

## Inmutabilidad y protección contra envenenamiento de caché

Las entradas del AC son inmutables por contenido: el servidor rechaza una sobrescritura divergente de
una `(tenant, action_digest)` existente con `409`, expuesto como `ConflictError`. Un
nuevo almacenamiento idéntico byte a byte es una operación idempotente sin efecto.
