# Descargar un blob

## Cuándo usar esta guía

Usted tiene un digest BLAKE3 y necesita los bytes. El SDK verifica el digest
del lado del cliente (`@noble/hashes`, en JS puro) de forma predeterminada (CTRL-CAS-002).

## Requisitos previos

- Un digest BLAKE3 conocido.
- Autenticación configurada.

## Ejemplo mínimo

```typescript
const data: Uint8Array = await client.get(digest);
// Already BLAKE3-verified; if verify failed, get() threw.
```

## Descargar a un archivo

`get` devuelve todo el `Uint8Array` verificado; escríbalo:

```typescript
import { writeFile } from "node:fs/promises";

async function getToFile(digest: string, dest: string): Promise<void> {
  const data = await client.get(digest); // throws DigestMismatchError if corrupt
  await writeFile(dest, data);
}
```

Una API de descarga por fragmentos/streaming no forma parte de esta versión.

## Desactivar la verificación

**Muy desaconsejado**. La desactivación existe solo para benchmarks de transporte.
Desactívela globalmente en la construcción (`clientVerify: false` — registra
`corelink.client.verify_disabled` según CTRL-CAS-002), o por llamada:

```typescript
const data = await client.get(digest, { verify: false });
```

## Errores

| Clase | Significado |
|---|---|
| `NotFoundError` | El digest no está en el CAS del tenant (404) |
| `GoneError` | Artefacto borrado (410); no lo resucite |
| `DigestMismatchError` | Bytes corruptos; no los use |
