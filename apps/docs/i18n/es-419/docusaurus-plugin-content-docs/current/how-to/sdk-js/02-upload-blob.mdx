# Subir un blob

## Cuándo usar esta guía

Usted tiene un `Uint8Array` o un `Buffer` de Node (que es un `Uint8Array`) y quiere que se
persista en el CAS de CoreLink. El SDK calcula el digest BLAKE3 por usted; opcionalmente
puede pasar un `expectedDigest` para afirmar que coincide localmente.

## Requisitos previos

- Autenticación configurada ([01-authenticate](./01-authenticate.mdx)).

## Ejemplo mínimo

```typescript
import { CoreLinkClient } from "@corelink/client";
import { readFile } from "node:fs/promises";

const client = new CoreLinkClient({ tenantId: "acme-corp" });
const data = await readFile("./build/output.tar");
const digest = await client.put(data);
console.log("stored:", digest);
await client.close();
```

`digest` es la cadena hexadecimal BLAKE3 de 64 caracteres.

## Blobs grandes

`put` recibe el arreglo de bytes completo (un almacén direccionable por contenido debe aplicar
hash al objeto completo para conocer su dirección, por lo que el digest se calcula sobre el
búfer completo). Lea el archivo en memoria y luego súbalo:

```typescript
import { readFile } from "node:fs/promises";

async function uploadLarge(path: string): Promise<string> {
  const data = await readFile(path); // Buffer is a Uint8Array
  return client.put(data);
}
```

Una API de subida por fragmentos/streaming no forma parte de esta versión.

## Idempotencia

`put` deduplica del lado del servidor; dos subidas de bytes idénticos se resuelven al
mismo digest sin doble cobro.

## Tipos de TypeScript

El paquete incluye declaraciones `.d.ts` completas:

```typescript
import type { BlobDigest, TenantId, PutOptions } from "@corelink/client";

const opts: PutOptions = { expectedDigest: "..." satisfies BlobDigest };
```
