# Autenticar el SDK JS/TS

## Cuándo usar esta guía

Usted instala `@corelink/client` en un contexto de Node.js o de un bundler moderno y
necesita llamar a cualquier API de caché. La autenticación por PAT es obligatoria; el cliente se niega a
construirse sin una.

## Requisitos previos

- Node.js 18+ (usa el `fetch` global) o cualquier bundler que apunte a ES2022. ESM es el valor predeterminado; `require()` de CommonJS no es compatible.
- `npm install @corelink/client`
- Un PAT generado en `https://humangr.com/corelink/tokens`.

## Variable de entorno recomendada (Node.js)

```bash
export CORELINK_PAT="corelink_dev_t_xxx.xxx.xxx"
```

```typescript
import { CoreLinkClient } from "@corelink/client";

// PAT is read from CORELINK_PAT; the constructor throws if neither the
// `pat` argument nor the env var is present.
const client = new CoreLinkClient({ tenantId: "acme-corp" });

// The first real call surfaces an invalid/revoked PAT as an AuthError (401).
const digest = await client.put(new TextEncoder().encode("ping"));
console.log("authenticated; wrote", digest);
await client.close();
```

## Navegador / bundler

Nunca incruste un PAT en el JS enviado al navegador. En su lugar, haga proxy a través de su propio
backend y reenvíe tokens de corta duración por usuario generados por su servidor.

```typescript
// frontend
const client = new CoreLinkClient({
  pat: await fetch("/api/corelink-token").then((r) => r.text()),
  tenantId: "acme-corp",
});
```

El endpoint `/api/corelink-token` debe validar la sesión del usuario final y
emitir un PAT con alcance de tarea que tenga los alcances mínimos requeridos.

## Prohibido: PAT en el código fuente versionado

```typescript
// DO NOT DO THIS
const client = new CoreLinkClient({
  pat: "corelink_dev_t_xxx.xxx.xxx",
  tenantId: "acme-corp",
});
```

Infringe CTRL-CRED-001. El lint de la CI marca las cadenas con apariencia de PAT codificadas de forma fija en el código.

## Verificar

```typescript
import { AuthError } from "@corelink/client";

try {
  // Any authenticated call works; `stat` is cheap and side-effect-free.
  await client.stat("0".repeat(64));
} catch (e) {
  if (e instanceof AuthError) {
    console.error("auth failed:", e.code);
    process.exit(1);
  }
  throw e;
}
```
