# Upload a blob

## When to use this guide

Tiene un `[]byte` y quiere persistirlo en el CAS de CoreLink. `Put`
calcula el digest BLAKE3 por usted — no hay forma de suministrar un
digest precalculado del lado del cliente en este SDK (a diferencia de
`expected_digest=` en `corelink-py`).

## Prerequisites

- Autenticación configurada ([01-authenticate](./01-authenticate.mdx)).

## Minimal example

```go
import (
    "context"
    "os"

    "go.corelink.humangr.com/corelink-go"
)

func upload(ctx context.Context, cli *corelink.Client, path string) (string, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        return "", err
    }
    digest, err := cli.Put(ctx, data)
    if err != nil {
        return "", err
    }
    return digest.Hash, nil
}
```

## No streaming upload on the native CAS surface

`Client` tiene exactamente tres métodos nativos de CAS — `Put`, `Get`,
`Stat` — y `Put` toma un `[]byte`, no un `io.Reader`; no hay
`PutStream` ni opción de tamaño de fragmento en esta superficie. Para
un archivo demasiado grande para mantener completamente en memoria,
use `Client.ByteStream().Write`, que transmite desde un `io.Reader`
contra la superficie REAPI v2, o lea el archivo en sus propios
fragmentos y ensamble la subida usted mismo.

## Idempotency

El CAS nativo está direccionado por contenido: dos llamadas a `Put`
con bytes idénticos resuelven al mismo digest, así que una subida
duplicada no se factura como almacenamiento separado.

## Context plumbing

El parámetro `context.Context` de `Put` se propaga hasta la solicitud
HTTP subyacente (`Client.do` construye la solicitud con
`http.NewRequestWithContext(ctx, ...)`), así que un contexto cancelado
o con tiempo agotado aborta un `Put` en curso.

## Errors

Los métodos de `Client` devuelven errores tipados que puede
comprobar con `errors.As`, no cadenas de mensaje simples:

| Error type | Cause | Action |
|---|---|---|
| `*corelink.AuthError` | El PAT fue rechazado, faltaba, o su tenant no coincidía con el tenant de la solicitud | Confirme el PAT/tenant con una llamada a `Stat` primero; si eso también falla, vea [Troubleshooting](./07-troubleshooting.mdx) |
| `*corelink.QuotaError` | La cuota de bytes o de solicitudes del tenant está agotada | Verifique los límites del plan antes de reintentar |
| `*corelink.DigestMismatchError` | Los bytes subidos se hashearon a un digest distinto del calculado por el servidor | Recalcule localmente; no reintente los mismos bytes a ciegas |

```go
digest, err := cli.Put(ctx, data)
if err != nil {
    var authErr *corelink.AuthError
    var quotaErr *corelink.QuotaError
    switch {
    case errors.As(err, &authErr):
        log.Fatalf("auth error (%d): %s", authErr.StatusCode, authErr.Message)
    case errors.As(err, &quotaErr):
        log.Fatalf("quota exceeded (%d): %s", quotaErr.StatusCode, quotaErr.Message)
    default:
        log.Fatalf("put failed: %v", err)
    }
}
```
