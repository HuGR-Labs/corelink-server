# Authenticate the Go SDK

## When to use this guide

Importa `go.corelink.humangr.com/corelink-go` y necesita llamar a
cualquier API que mute o lea la caché. La autenticación por PAT es
obligatoria; el SDK se niega a construir un cliente sin uno.

## Prerequisites

- Go 1.22+.
- `corelink-go` es un módulo Go puro — sin cgo, sin biblioteca nativa,
  nada que compilar primero. Obténgalo mediante el proxy de módulos
  propio de CoreLink:

  ```bash
  GOPROXY=https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct go get go.corelink.humangr.com/corelink-go@v0.1.0
  ```

  El parámetro `GOPROXY` es obligatorio, no un lujo:
  `go.corelink.humangr.com` no tiene registro DNS, así que un `go get`
  simple falla con "no such host". El módulo se sirve desde el proxy
  propio de CoreLink — la primera entrada de la lista. La segunda
  entrada, `https://proxy.golang.org`, es la que obtiene las
  dependencias públicas ordinarias de este módulo; `direct` es el
  respaldo si ambos proxies fallan.
- Un tenant de CoreLink; PAT generado en
  `https://humangr.com/corelink/en/customer/keys`.

## Construct the client

```go
package main

import (
    "context"
    "log"
    "os"

    "go.corelink.humangr.com/corelink-go"
)

func main() {
    client, err := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        TenantID: "acme-corp",
    })
    if err != nil {
        log.Fatal(err)
    }
    defer client.Close()

    ctx := context.Background()
    digest, err := client.Put(ctx, []byte("hello"))
    if err != nil {
        log.Fatal(err)
    }
    data, err := client.Get(ctx, digest)
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("wrote+read %d bytes at %s", len(data), digest.Hash)
}
```

`corelink.NewClient` toma un struct `Config` más opciones funcionales
opcionales (`corelink.WithTenantID`, para fijar el tenant por separado
del literal `Config`). `Config.Endpoint` y `Config.PAT` son
obligatorios; `NewClient` devuelve un error si alguno está vacío.
`Config.TenantID` es opcional en general — un PAT ya lleva su propio
tenant — pero las rutas nativas de CAS (`Put`/`Get`/`Stat`) necesitan
uno, así que configúrelo a menos que solo use la superficie REAPI v2.

## Forbidden: PAT in struct literal in committed code

```go
// DO NOT DO THIS
client, _ := corelink.NewClient(corelink.Config{
    Endpoint: "https://corelink-api.humangr.com",
    PAT:      "corelink_pat_01ARZ3NDEKTSV4RRFFQ69G5FAV.4pT7q1yZ9vX2wL8cR5nB3sD6fH0jK1mQ8aV2eS.7bY4tN9oL2x",
    TenantID: "acme-corp",
})
```

Viola CTRL-CRED-001. Lea `Config.PAT` únicamente desde
`os.Getenv("CORELINK_PAT")`.

## Verify

No hay método `Whoami` en este cliente. `NewClient` en sí solo valida
la forma de la configuración y no realiza ninguna llamada de red; un
PAT inválido o revocado se manifiesta la primera vez que efectivamente
llama a `Put`/`Get`/`Stat`, como un `*corelink.AuthError` tipado:

```go
digest, err := client.Put(ctx, []byte("healthcheck"))
if err != nil {
    var authErr *corelink.AuthError
    if errors.As(err, &authErr) {
        log.Fatalf("auth failed (%d): %s", authErr.StatusCode, authErr.Message)
    }
    log.Fatalf("request failed: %v", err)
}
log.Println("authenticated; wrote", digest.Hash)
```

## Self-service PAT issuance

Authenticated tenants can issue an additional PAT with `POST /v1/pats`;
`POST /v1/customer/keys` is the compatible dashboard alias. Both routes use
the same per-tenant `pat-issue` limiter (burst 10, then 10/hour, one token
every 360 seconds), enforced before mint and audit. Handle `429` and its
`Retry-After` header; the plaintext token is returned only once.
