# Download a blob

## When to use this guide

You hold a BLAKE3 digest and need the bytes. `Get` verifies the digest
client-side when the client was constructed with verify enabled (the
default — see [Authenticate](./01-authenticate.mdx)).

## Prerequisites

- A known BLAKE3 digest.
- Authentication configured.

## Minimal example

```go
func download(ctx context.Context, cli *corelink.Client, digest string) ([]byte, error) {
    return cli.Get(ctx, digest)
}
```

If verification fails, `Get` returns an error containing
`COR_CAS_DIGEST_MISMATCH` and no bytes.

## No streaming download

There is no `GetStream` — `Get` returns the full `[]byte`. If you need to
stream a download without buffering the whole blob in memory, use
`corelink-py`'s `AsyncCoreLinkClient.get_stream(digest)` (an async context
manager you iterate with `async for chunk in stream:`) — that method exists
only on the async Python client, not the sync one or this Go SDK.

## Verification is a construction-time setting, not a per-call flag

There is no `WithoutVerify()` call-site option. Client-verify is set once,
at `NewClient`, via `Config.ClientVerify` +
`Config.ClientVerifyExplicitFalse` (see
[Authenticate](./01-authenticate.mdx)) — every `Get` on that client either
verifies or doesn't, for the client's lifetime.

## Errors

Plain `error` values (message strings) — there is no
`*corelink.NotFoundError`, `*corelink.DigestMismatchError`, or
`*corelink.RegionError` type:

| Message contains | Cause |
|---|---|
| `invalid digest length %d (expected 64)` | The digest passed to `Get` isn't 64 hex chars — recompute (CoreLink digests are BLAKE3, not SHA-256). |
| `COR_CAS_DIGEST_MISMATCH: digest mismatch for %s` | Client-verify caught a BLAKE3 mismatch. Possible corruption in transit; retry, and open a support ticket if it persists. |
| `COR_CAS_VERIFY_DISABLED` | `Get` was called on a client constructed with verify explicitly disabled — expected if you meant to disable it. |
| `get verify failed (rc=%d)` | Non-zero, non-mismatch return from the native call. |
