# Troubleshooting

## When to use this guide

Una llamada de `corelink-go` devolvió un error. `corelink-go` devuelve
errores tipados que se comprueban con `errors.As` / `errors.Is` — no
cadenas de mensaje simples ni un diagnóstico `Doctor`. No hay
`Whoami`, ni registro estructurado, en este SDK hoy.

Si quiere el diagnóstico `doctor` de 8 verificaciones o una
comprobación de identidad guiada por CLI, use la [CLI de
`corelink`](../../reference/cli/doctor.mdx) o los SDKs de
[Python](../sdk-python/07-troubleshooting.mdx) /
[JS](../sdk-js/07-troubleshooting.mdx), que tienen superficies más
ricas.

## Errors you'll actually see

| Error type / value | Cause | Fix |
|---|---|---|
| plain error: `Config.Endpoint is required` | `Config.Endpoint` estaba vacío en `NewClient` | Configure `Config.Endpoint` (`https://corelink-api.humangr.com`). |
| plain error: `Config.PAT is required` | `Config.PAT` estaba vacío en `NewClient` | Configure `CORELINK_PAT` y léalo en `Config.PAT` usted mismo — `NewClient` no lee variables de entorno por usted. |
| plain error: `CAS operations require a tenant` | Se llamó a `Put`/`Get`/`Stat` sin `Config.TenantID` configurado | Pase `TenantID` en `Config`, o use `corelink.WithTenantID(...)`. |
| `*corelink.AuthError` | El PAT fue rechazado, faltaba, o su tenant no coincidía con el tenant de la solicitud (HTTP 401/403) | Verifique que el PAT se copió completo (`corelink_<env>_<token_id>.<random_secret>.<hmac_sig>`), sin truncar. |
| `*corelink.QuotaError` | La cuota de bytes o de solicitudes del tenant está agotada (HTTP 402) | Verifique los límites del plan antes de reintentar. |
| `*corelink.RateLimitError` | Se está limitando al llamador (HTTP 429); `RetryAfter` lleva el backoff anunciado por el servidor, cuando se envía | Espere `RetryAfter` y reintente. |
| `*corelink.RegionError` | La solicitud llegó a, o pidió, una región que no puede servir a este tenant u objeto | Enrute la solicitud a `RegionError.Region` en su lugar. |
| `*corelink.NotFoundError` | El digest, acción o recurso solicitado no existe en el almacén del tenant (HTTP 404) | Confirme el digest con `Stat` antes de `Get`. |
| `*corelink.DigestMismatchError` | El contenido se hasheó a un digest distinto del esperado — ya sea que el llamador envió el digest equivocado en un `Put`, o la verificación del lado del cliente de `Get` detectó una lectura corrupta o envenenada | Recalcule el digest localmente; en un desajuste de `Get`, reintente — desajustes persistentes en el mismo digest necesitan un ticket de soporte. |
| `corelink.ErrActionCacheMiss` (sentinel) | `ActionCache().Get` no encontró resultado para el digest de acción | Ruta ordinaria de cache-miss — compárela con `errors.Is`, luego ejecute la acción y llame a `Update`. |
| digest validation error: `digest hex must be 64 characters` / `digest hex must be lower-case hex` | `Digest.Validate()` rechazó un digest malformado pasado a `Get`/`Stat` | Recalcule — los digests de CoreLink son BLAKE3 (64 caracteres hex en minúscula), no SHA-256. |

## Matching typed errors

```go
digest, err := client.Put(ctx, data)
if err != nil {
    var authErr *corelink.AuthError
    var quotaErr *corelink.QuotaError
    var rateErr *corelink.RateLimitError
    switch {
    case errors.As(err, &authErr):
        log.Fatalf("auth error (%d): %s", authErr.StatusCode, authErr.Message)
    case errors.As(err, &quotaErr):
        log.Fatalf("quota exceeded (%d): %s", quotaErr.StatusCode, quotaErr.Message)
    case errors.As(err, &rateErr):
        time.Sleep(rateErr.RetryAfter)
        // retry
    default:
        log.Fatalf("put failed: %v", err)
    }
}
```

`corelink.ErrActionCacheMiss` es un centinela, no un tipo — compárelo
con `errors.Is`, no con una aserción de tipo:

```go
result, err := client.ActionCache().Get(ctx, actionDigest)
if errors.Is(err, corelink.ErrActionCacheMiss) {
    // cache miss, not a failure
}
```

## Confirm the client is talking to the server at all

No hay `Whoami`. Use `Client.Health` para una comprobación de
disponibilidad ligera, o un `Put`/`Get` real:

```go
status, err := client.Health(ctx)
if err != nil || !status.OK {
    log.Fatalf("server not reachable: %v", err)
}
log.Println("server ok")
```

## `Capabilities` returns an error, not data

`Client.Capabilities` no tiene un endpoint de servidor al cual llamar.
La tabla de rutas de REAPI v2 (`bazel_v2.rs`) monta exactamente cinco
rutas — lectura de CAS, escritura de CAS, lectura de AC, escritura de
AC, y `findMissingBlobs` — y ninguna de ellas es un endpoint de
capacidades. `Capabilities` no realiza ninguna llamada de red; devuelve
el `ServerCapabilities` de valor cero y un error que lo explica. Use
`Client.Health` para una comprobación de disponibilidad en su lugar.

## `ClientVerify` cannot be turned off with a plain `false`

`Config.ClientVerify` está habilitado por defecto: el valor cero
(`false`) es indistinguible de "no configurado", así que optar por
desactivar el re-hasheo del lado del cliente requiere un segundo
campo, deliberado — `ClientVerifyExplicitFalse: true`. Verifique
`Client.IsClientVerifyEnabled()` si necesita confirmar en qué modo
terminó un cliente construido.

## Filing a bug

Incluya el mensaje de error exacto (`err.Error()`) y su versión de
`corelink-go` (`go.mod` / `go list -m
go.corelink.humangr.com/corelink-go`). Nunca incluya su PAT.
