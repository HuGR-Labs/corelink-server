# Autenticar el SDK de Python

## Cuándo usar esta guía

Usted ha instalado `corelink-py` y necesita llamar a cualquier API que modifique
o lea el caché. Se requiere un PAT en cada solicitud, excepto en `corelink.ping`.

Si solo necesita leer la versión actual del SDK, consulte
[Solución de problemas](./07-troubleshooting.mdx).

## Requisitos previos

- Python 3.10+ (`asyncio` se usa en todos los ejemplos de esta sección).
- `pip install corelink-py` (wheels publicados en PyPI; bindings pyO3).
- Un tenant de CoreLink. Emita un PAT en `https://humangr.com/corelink/en/customer/keys`.

## Recomendado: variable de entorno

El SDK lee `CORELINK_PAT` automáticamente:

```bash
export CORELINK_PAT="corelink_dev_t_xxx.xxx.xxx"
```

```python
import asyncio
from corelink import CoreLinkClient

async def main() -> None:
    async with CoreLinkClient(tenant_id="acme-corp") as client:
        info = await client.whoami()
        print(info.tenant_id, info.scopes)

asyncio.run(main())
```

El bloque `with` garantiza que el pool HTTP/2 subyacente se cierre de forma limpia.

## Alternativa: archivo de configuración

Para el desarrollo local, cree `~/.corelink/config.toml`:

```toml
[auth]
pat = "corelink_dev_t_xxx.xxx.xxx"

[defaults]
tenant_id = "acme-corp"
```

El SDK recurre a este archivo si `CORELINK_PAT` no está definido.

## Prohibido: PAT como argumento de función en código publicado

No haga commit de código que incruste un PAT de forma fija:

```python
# DO NOT DO THIS
client = CoreLinkClient(pat="corelink_dev_t_xxx.xxx.xxx", tenant_id="acme-corp")
```

Esto infringe CTRL-CRED-001. Use únicamente variables de entorno o archivos de
configuración.

## Verificar

```python
import asyncio
from corelink import CoreLinkClient, AuthError

async def verify() -> None:
    try:
        async with CoreLinkClient() as client:
            await client.whoami()
            print("ok")
    except AuthError as e:
        print(f"auth failed: {e.code}")

asyncio.run(verify())
```

Código de salida esperado `0` en caso de éxito; `1` en `AuthError`.
