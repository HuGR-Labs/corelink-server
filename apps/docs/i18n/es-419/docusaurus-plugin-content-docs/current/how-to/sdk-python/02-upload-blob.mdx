# Subir un blob

## Cuándo usar esta guía

Use esto cuando necesite persistir bytes arbitrarios (una salida de build, un peso
de modelo, un tarball empaquetado) en el CAS de CoreLink y quiera que el SDK
calcule el digest BLAKE3 por usted.

Si ya tiene un digest y quiere omitir el recálculo, proporciónelo mediante
`expected_digest=`.

## Requisitos previos

- Autenticación configurada (consulte [01-authenticate](./01-authenticate.mdx)).

## Ejemplo mínimo

```python
import asyncio
from pathlib import Path
from corelink import AsyncCoreLinkClient

async def main() -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        data = Path("./build/output.tar").read_bytes()
        digest = await client.put(data)
        print(f"stored: {digest}")  # 64-char BLAKE3 hex
```

> El gemelo síncrono es `corelink.CoreLinkClient` — los mismos métodos sin
> `async`/`await` (`digest = client.put(data)`), usados con un bloque `with` simple.

## Subida en streaming (blobs grandes)

Para archivos grandes, use la sobrecarga de streaming para evitar cargar el archivo
completo en memoria — el digest BLAKE3 se calcula en una única pasada rebobinada
sobre el handle de archivo abierto, y luego el mismo handle se transmite al
servidor:

```python
async def upload_large(path: str) -> str:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        with open(path, "rb") as f:
            return await client.put_stream(f, chunk_size=4 * 1024 * 1024)
```

## Idempotencia

`put` es idempotente respecto al digest. Una segunda subida de bytes idénticos
devuelve el mismo digest sin costo adicional de almacenamiento (dedupe CTRL-CAS-001).

## Errores

| Excepción | Causa | Acción |
|---|---|---|
| `CoreLinkAuthError` | PAT ausente o revocado (HTTP 401) | Vuelva a ejecutar [01-authenticate](./01-authenticate.mdx) |
| `CoreLinkQuotaError` | Tenant por encima de la cuota (HTTP 402) | Inspeccione `corelink stat`; consulte [solución de problemas](./07-troubleshooting.mdx) |
| `CoreLinkDigestMismatchError` | `expected_digest` no coincidió con `blake3(body)` (HTTP 422) | Vuelva a calcular localmente; no reintente a ciegas |

Todas se importan de `corelink.exceptions` (o del paquete de nivel superior
`corelink`) y son subclases de `CoreLinkError`.
