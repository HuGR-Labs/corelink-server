# Descargar un blob

## Cuándo usar esta guía

Usted tiene un digest BLAKE3 (de un `put` anterior, de un resultado del Action
Cache o de metadatos de un peer) y necesita materializar los bytes localmente. El
SDK verifica el hash del lado del cliente por defecto (CTRL-CAS-002).

## Requisitos previos

- Un digest BLAKE3 conocido.
- Autenticación configurada.

## Ejemplo mínimo

```python
import asyncio
from corelink import AsyncCoreLinkClient

async def main() -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        digest = "0123456789abcdef" * 4
        data = await client.get(digest)
        # data is already BLAKE3-verified; if verify failed, get() raises.
        with open("./out.bin", "wb") as f:
            f.write(data)
```

> El gemelo síncrono es `corelink.CoreLinkClient` — `data = client.get(digest)`
> dentro de un bloque `with` simple.

## Descarga en streaming

```python
async def stream_to_file(digest: str, dest: str) -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        async with client.get_stream(digest) as stream:
            with open(dest, "wb") as f:
                async for chunk in stream:
                    f.write(chunk)
        # stream.__aexit__ raises if final verify fails.
```

El verificador de streaming calcula el hash de forma incremental y valida la raíz
BLAKE3 en cuanto llega el último chunk. Si la raíz no coincide,
`stream.__aexit__` lanza `CoreLinkDigestMismatchError`; el SDK nunca mueve el
archivo a su lugar final, por lo que eliminar la salida parcial es
responsabilidad de quien llama.

## Desactivar la verificación

**Muy desaconsejado**. La desactivación existe solo para benchmarks que necesitan
medir la latencia bruta de transporte. Establecer `verify=False` emite una línea
de log `WARNING` `corelink.client.verify_disabled`, conforme a CTRL-CAS-002.

```python
data = await client.get(digest, verify=False)
```

Si se descubre a punto de usar esta bandera, abra primero una incidencia.

## Errores

| Excepción | Significado |
|---|---|
| `CoreLinkNotFoundError` | El digest no existe en el CAS del tenant (HTTP 404), o fue borrado (HTTP 410) |
| `CoreLinkDigestMismatchError` | Bytes corrompidos en tránsito; no use los datos |

Todas se importan de `corelink.exceptions` (o del paquete de nivel superior
`corelink`) y son subclases de `CoreLinkError`.
