## How this page is updated

When CoreLink declares a SEV-1 or SEV-2 security incident, the on-call
incident commander adds a row to this table within TBD business days of
incident resolution. The post-mortem link points to a public, blameless
post-mortem authored from the internal template.

We also publish customer-facing status updates on `status.corelink.dev`
during active incidents.
