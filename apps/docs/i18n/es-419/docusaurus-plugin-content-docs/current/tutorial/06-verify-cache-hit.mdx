# Verificar la tasa de aciertos del caché

El tutorial solo está completo cuando puede demostrar que el caché funciona. Esta
página reúne tres verificaciones independientes.

## A. Logs de Bazel BES / Buck2

Bazel:

```bash
bazel build //:hello 2>&1 | grep -E "remote cache hit|disk cache hit|processes:"
# INFO: 12 processes: 11 remote cache hit, 1 internal.
```

Buck2:

```bash
buck2 build //:hello --show-output 2>&1 | grep -iE "cache hits"
```

Una build 100% verde que imprime **0 processes** es la señal aislada más fuerte —
Bazel/Buck2 cortocircuitó cada acción a través del caché.

## B. Microbenchmark de CLI

Ejecute el `corelink bench` integrado (escribe un blob determinista de 16 KiB 50× y
luego lo lee 50×):

```bash
corelink bench --put 50 --get 50
# put p50=8.2ms  p95=13.1ms  err=0/50
# get p50=2.1ms  p95= 4.8ms  err=0/50 hit_ratio=100%
```

`hit_ratio=100%` en la pasada de lectura confirma que las solicitudes de la
segunda en adelante se sirven desde el caché.

## C. Panel de la IU de administración

1. Abra `https://corelink-app.humangr.com/orgs/<your-org>/observability`.
2. Elija **Cache hit ratio (5m, by tenant)**.
3. Dispare una build nueva (`bazel clean && bazel build //...`).
4. La serie debería saltar a ~100% después de la primera pasada en caliente.

El panel de Grafana de la tasa de aciertos está documentado en
`dashboards/cache_hit_ratio.json`; los umbrales de alerta se encuentran en
`infra/alerts/cache_hit_ratio.yaml`.

## Solución de problemas

| Síntoma | Causa probable | Corrección |
| --- | --- | --- |
| `hit_ratio=0%` en la segunda build | el caché de disco local sirvió la solicitud, nunca tocó el remoto | `bazel clean` y establezca `build --noremote_accept_cached=false` para forzar la lectura remota |
| Errores `UNAUTHENTICATED` | PAT vencido o entorno incorrecto | Vuelva a ejecutar `corelink doctor --check-auth`, regenere el PAT |
| `COR_CAS_DIGEST_MISMATCH` | bytes corrompidos en tránsito | `client_verify` rechazó el blob — abra una incidencia, no desactive la verificación |
| Lento `p95 > 50ms` | lejos de la edge más cercana | Fije la región más cercana en `.bazelrc`: `build --remote_cache=https://<region>.<tenant>.corelink.humangr.com/v1/cache` |
