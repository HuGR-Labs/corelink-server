# Native SDK quickstart

If you are building a custom pipeline (ML training cache, CI artifact store, data lake), use the language SDKs rather than Bazel/Buck2. All SDKs share the same REAPI v2 semantics and enable `client_verify` by default ([CTRL-CAS-002](../reference/reapi/index.mdx)).

## Python — `corelink-py`

```bash
pip install corelink-py
```

```python
import asyncio
import os
from corelink import CoreLinkClient

async def main() -> None:
    async with CoreLinkClient(
        endpoint="https://corelink-api.humangr.com",
        pat=os.environ["CORELINK_PAT"],
    ) as client:
        digest = await client.put(b"hello, corelink")
        blob = await client.get(digest)
        assert blob == b"hello, corelink"
        print(f"OK — digest={digest.hash[:12]}... size={digest.size_bytes}")

asyncio.run(main())
```

Full example: [`examples/python/quickstart.py`](https://github.com/HumanGuardrail/corelink-server/tree/main/examples/python/quickstart.py).

## Go — `corelink-go`

```bash
go get go.corelink.humangr.com/corelink-go@latest
```

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, err := corelink.NewClient(ctx, corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
    })
    if err != nil {
        panic(err)
    }
    defer client.Close()

    digest, err := client.Put(ctx, []byte("hello, corelink"))
    if err != nil {
        panic(err)
    }
    blob, err := client.Get(ctx, digest)
    if err != nil {
        panic(err)
    }
    fmt.Printf("OK — digest=%s... size=%d bytes (%d)\n", digest.Hash[:12], digest.SizeBytes, len(blob))
}
```

Full example: [`examples/go/quickstart.go`](https://github.com/HumanGuardrail/corelink-server/tree/main/examples/go/quickstart.go).

## Node / TypeScript — `@corelink/client`

```bash
pnpm add @corelink/client
```

```ts
import { CoreLinkClient } from "@corelink/client";

const client = new CoreLinkClient({
  endpoint: "https://corelink-api.humangr.com",
  pat: process.env.CORELINK_PAT!,
});

const digest = await client.put(new TextEncoder().encode("hello, corelink"));
const blob = await client.get(digest);
console.log(`OK — digest=${digest.hash.slice(0, 12)}... size=${digest.sizeBytes}`);
```

Full example: [`examples/javascript/quickstart.ts`](https://github.com/HumanGuardrail/corelink-server/tree/main/examples/javascript/quickstart.ts).

## Client-verify default-on

All SDKs re-hash blob bytes on read and reject mismatches (`COR_CAS_DIGEST_MISMATCH`). This catches tampering between cache server and client. Disable only with explicit opt-in (`client_verify=False`), and an audit warning is logged.
