## How to refresh

```bash
# 1. seed MT-stubs from translation memory (where TMX entries exist)
pnpm tsx scripts/mt-stub-seed.ts

# 2. regenerate this report
pnpm tsx scripts/i18n-coverage-report.ts

# 3. export XLIFF 2.1 for the translator vendor
pnpm i18n:export
```

## Acceptance

Per WT-R4-1 acceptance, coverage = `(translated + mt-stub) / total ≥ 80 %` for both pt-BR and es-419. CI gate `i18n-coverage.ts` enforces the same threshold at PR time (any new content without a stub fails the build).
