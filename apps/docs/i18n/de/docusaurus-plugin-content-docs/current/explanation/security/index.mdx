# Security overview

CoreLink is a multi-tenant shared cache. The blast radius of a compromise is
*cross-tenant*, so the security objectives are ordered strictly:

1. **Integrity of every artefact** — no blob served diverges from the
   requested hash (`INV-CAS-INTEGRITY`).
2. **Tenant isolation** — tenant A never reads, writes, or enumerates blobs
   belonging to tenant B (`INV-TenantIsolation`, TLA+ model-checked).
3. **Confidentiality** at rest (AES-256-GCM via R2 SSE) and in flight
   (TLS 1.3 + mTLS between control and data planes).
4. **Availability isolation** — a DoS aimed at one tenant must not consume
   another tenant's SLO budget.
5. **Auditability** — every write or admin operation produces an immutable
   audit-log event (`INV-AUDIT-APPEND-ONLY`).

## Defence-in-depth highlights

- **BYOK** — bring your own KMS (AWS KMS, GCP KMS, Azure Key Vault, HashiCorp
  Vault) for enterprise tenants. See [BYOK customer-managed keys](./byok).
- **Envelope encryption** — every blob is encrypted with a per-tenant data
  encryption key (DEK) wrapped by the tenant's KMS root key.
- **Append-only audit chain** — Merkle-linked audit log with RFC 6962
  inclusion proofs and a 7-year retention window. See
  [Audit chain](./audit-chain).
- **SLSA L3 supply chain** — every release binary carries a Sigstore
  provenance attestation verifiable against the public transparency log.
- **RFC 8785 JCS canonicalization** — every signed payload is canonicalized
  before signing so signature verification is deterministic across runtimes.

## Cryptography baseline

| Use | Algorithm | Notes |
| --- | --- | --- |
| Content hashing (primary) | BLAKE3 | 32-byte digest |
| Content hashing (REAPI legacy) | SHA-256 | Bazel/Buck compatibility |
| HMAC (path, nonces) | HMAC-SHA256 | — |
| Key derivation | HKDF-SHA256 | per-purpose `info` string |
| At-rest encryption | AES-256-GCM | R2 SSE |
| Transport | TLS 1.3 | AES-256-GCM / ChaCha20-Poly1305 |
| Release signing | Ed25519 via Sigstore/cosign | offline HSM-backed key |

Banned: MD5, SHA-1, DES/3DES, RC4, ECB, RSA < 2048, hand-rolled cryptography.
