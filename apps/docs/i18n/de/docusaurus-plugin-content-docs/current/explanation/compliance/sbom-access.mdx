# SBOM access

> **DRAFT — pending Legal + Finance + Security review.** The procurement path
> below describes the *intended* customer-facing process; it is not yet
> contractually offered.

## What we publish

- **Format:** CycloneDX 1.5+ JSON (canonical per ADR-0014). SPDX 2.3+ available
  on request.
- **Cadence:** generated on every release build. The separate CAS signing path
  signs its gated release artifacts; customer distribution is not offered yet.
- **Coverage:** Worker, Container, and CLI binaries — Rust crates and JS deps
  inclusive.

## How enterprise customers request the SBOM

1. Open a support ticket of type **"Procurement / Security Review"**.
2. Provide your account ID and the release version you need the SBOM for.
3. We respond within TBD business days with a time-limited download URL.

## Signature verification

This draft does not expose a customer SBOM signature to verify today. The
former Worker OCI image lane never emitted a Fulcio certificate or Rekor entry
and was removed after review found that it never executed. Separate
release-SLSA and CAS signing paths remain active and independently gated; this
page does not claim that Sigstore is absent everywhere.

## Cross-functional review checklist

- [ ] Security Lead — confirm SBOM scope and signing key URL.
- [ ] Legal — confirm NDA or licensing terms gating distribution.
- [ ] Procurement — confirm SLA on ticket response time.
