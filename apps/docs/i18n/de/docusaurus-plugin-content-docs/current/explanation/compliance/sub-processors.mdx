# Sub-processors

## Benachrichtigungsrichtlinie

CoreLink verpflichtet sich zu einer **30-tägigen Vorankündigung**, bevor ein neuer
Sub-Prozessor mit der Verarbeitung personenbezogener Kundendaten beginnt, und bevor
ein bestehender Sub-Prozessor seine Verarbeitungsrolle, Region oder eigene
Sub-Prozessorliste wesentlich ändert (DSGVO Art. 28(2)).

Um eine zusätzliche E-Mail-Adresse (Sicherheitsteam, DSB, Einkauf) für
Änderungsbenachrichtigungen anzumelden, senden Sie eine E-Mail an
[privacy@humangr.com](mailto:privacy@humangr.com) mit dem Betreff
„Anmeldung für Sub-Prozessor-Benachrichtigungen" und Ihrer Mandanten-ID.

## Anmeldung für Änderungsbenachrichtigungen

1. Senden Sie eine E-Mail an **privacy@humangr.com** mit dem Betreff „Anmeldung für Sub-Prozessor-Benachrichtigungen".
2. Geben Sie die E-Mail-Adresse an, die DKIM-signierte Benachrichtigungen erhalten soll.
3. Die Anmeldung wird innerhalb eines Werktages per Opt-in-Link bestätigt.
