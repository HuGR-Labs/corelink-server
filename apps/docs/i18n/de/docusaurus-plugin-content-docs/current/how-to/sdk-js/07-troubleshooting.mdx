# Fehlerbehebung

## Wann Sie diese Anleitung verwenden

Ein `@corelink/client`-Aufruf wirft eine Ausnahme oder hängt. Jeder Fehler erweitert
`CoreLinkError` und trägt einen `status` (HTTP-Status, sofern serverseitig entstanden)
und einen kurzen `code` (die Begründungszeichenkette des Servers). Untersuchen Sie sie:

## Diagnoseablauf

```typescript
import { CoreLinkError } from "@corelink/client";

try {
  await client.get(digest);
} catch (e) {
  if (e instanceof CoreLinkError) {
    console.error(`${e.name} status=${e.status} code=${e.code}: ${e.message}`);
  }
  throw e;
}
```

## Häufige Fehler

Ordnen Sie die geworfene Klasse ihrer Ursache und Behebung zu:

| Klasse | Status | Erste Maßnahme |
|---|---|---|
| `AuthError` | 401 | Exportieren Sie `CORELINK_PAT` erneut; falls widerrufen, erzeugen Sie ein neues PAT. |
| `ForbiddenError` | 403 | Falscher Tenant, oder dem PAT fehlt die erforderliche Cache-Berechtigung. |
| `QuotaError` | 402 | Tenant über seiner Speichergrenze / Ausgabenobergrenze. |
| `NotFoundError` / `ActionCacheMiss` | 404 | Digest / Action für diesen Tenant nicht gespeichert. |
| `GoneError` | 410 | Artefakt wurde gelöscht (GDPR/DSR); es kehrt nicht zurück. |
| `DigestMismatchError` | 422 / verify | Verwerfen Sie die Bytes; erneut herunter- oder hochladen. |
| `RateLimitError` | 429 | Automatisch erneut versucht; falls es weiterhin auftritt, verringern Sie die Nebenläufigkeit. |
| `ServerError` | 5xx | Vorübergehender Backend-Fehler; mit Backoff erneut versuchen. |
| `ConnectError` | — | Transportfehler; Netzwerk / `baseUrl` prüfen. |

## Kein nativer oder WASM-Build-Schritt

`@corelink/client` ist reines JavaScript (BLAKE3 über `@noble/hashes`). Es gibt kein
`.wasm`-Artefakt zum Bündeln und keine Bundler-Asset-Regel zu konfigurieren — falls ein
Auflösungsfehler auftritt, handelt es sich um ein gewöhnliches ESM-Paketauflösungsproblem, nicht um ein WASM-Problem.

## Lebenszyklus

`close()` ist heute eine No-Op (das SDK verwendet das Plattform-`fetch` und hält keinen
dauerhaften Pool), aber rufen Sie es dennoch auf, damit Ihr Code korrekt bleibt, falls eine
künftige Version Pooling hinzufügt:

```typescript
const client = new CoreLinkClient({ tenantId: "acme-corp" });
try {
  await client.get(digest);
} finally {
  await client.close();
}
```

## Ausführliche Protokollierung

```bash
export CORELINK_LOG=debug
```

Strukturierte JSON-Protokolle gehen an `stderr`. Leiten Sie sie über `jq`:

```bash
node ./script.mjs 2>&1 | jq 'select(.level=="error")'
```

## Einen Fehler melden

Fügen Sie die Ausgabe von `corelink doctor --json` bei. Fügen Sie niemals Ihr PAT bei.
