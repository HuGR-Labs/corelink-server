# Ein Blob hochladen

## Wann Sie diese Anleitung verwenden

Sie haben ein `Uint8Array` oder ein Node-`Buffer` (das ein `Uint8Array` ist) und möchten es
im CoreLink-CAS persistieren. Das SDK berechnet den BLAKE3-Digest für Sie; optional
können Sie ein `expectedDigest` übergeben, um zu bestätigen, dass es lokal übereinstimmt.

## Voraussetzungen

- Authentifizierung konfiguriert ([01-authenticate](./01-authenticate.mdx)).

## Minimalbeispiel

```typescript
import { CoreLinkClient } from "@corelink/client";
import { readFile } from "node:fs/promises";

const client = new CoreLinkClient({ tenantId: "acme-corp" });
const data = await readFile("./build/output.tar");
const digest = await client.put(data);
console.log("stored:", digest);
await client.close();
```

`digest` ist die 64 Zeichen lange BLAKE3-Hex-Zeichenkette.

## Große Blobs

`put` nimmt das vollständige Byte-Array entgegen (ein inhaltsadressierbarer Speicher muss das
gesamte Objekt hashen, um dessen Adresse zu kennen, daher wird der Digest über den vollständigen
Puffer berechnet). Lesen Sie die Datei in den Speicher und laden Sie sie dann hoch:

```typescript
import { readFile } from "node:fs/promises";

async function uploadLarge(path: string): Promise<string> {
  const data = await readFile(path); // Buffer is a Uint8Array
  return client.put(data);
}
```

Eine gestückelte/Streaming-Upload-API ist nicht Teil dieser Version.

## Idempotenz

`put` dedupliziert serverseitig; zwei Uploads identischer Bytes werden ohne doppelte
Abrechnung zum selben Digest aufgelöst.

## TypeScript-Typen

Das Paket liefert vollständige `.d.ts`-Deklarationen:

```typescript
import type { BlobDigest, TenantId, PutOptions } from "@corelink/client";

const opts: PutOptions = { expectedDigest: "..." satisfies BlobDigest };
```

## Fehler

| Klasse | Ursache | Aktion |
|---|---|---|
| `AuthError` | PAT fehlt oder wurde widerrufen | [01-authenticate](./01-authenticate.mdx) |
| `QuotaError` | Tenant über dem Kontingent | [Fehlerbehebung](./07-troubleshooting.mdx) |
| `DigestMismatchError` | `expectedDigest` falsch | Neu berechnen |
