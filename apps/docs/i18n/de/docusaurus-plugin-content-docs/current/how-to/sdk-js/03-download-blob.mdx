# Ein Blob herunterladen

## Wann Sie diese Anleitung verwenden

Sie besitzen einen BLAKE3-Digest und benötigen die Bytes. Das SDK überprüft den Digest
standardmäßig clientseitig (reines JS, `@noble/hashes`) (CTRL-CAS-002).

## Voraussetzungen

- Ein bekannter BLAKE3-Digest.
- Authentifizierung konfiguriert.

## Minimalbeispiel

```typescript
const data: Uint8Array = await client.get(digest);
// Already BLAKE3-verified; if verify failed, get() threw.
```

## In eine Datei herunterladen

`get` gibt das gesamte überprüfte `Uint8Array` zurück; schreiben Sie es heraus:

```typescript
import { writeFile } from "node:fs/promises";

async function getToFile(digest: string, dest: string): Promise<void> {
  const data = await client.get(digest); // throws DigestMismatchError if corrupt
  await writeFile(dest, data);
}
```

Eine gestückelte/Streaming-Download-API ist nicht Teil dieser Version.

## Verifizierung abschalten

**Dringend abgeraten**. Die Abschaltung existiert nur für Transport-Benchmarks.
Deaktivieren Sie sie global bei der Konstruktion (`clientVerify: false` — protokolliert
`corelink.client.verify_disabled` gemäß CTRL-CAS-002) oder pro Aufruf:

```typescript
const data = await client.get(digest, { verify: false });
```

## Fehler

| Klasse | Bedeutung |
|---|---|
| `NotFoundError` | Digest nicht im Tenant-CAS (404) |
| `GoneError` | Artefakt gelöscht (410); nicht wiederherstellen |
| `DigestMismatchError` | Bytes beschädigt; nicht verwenden |
