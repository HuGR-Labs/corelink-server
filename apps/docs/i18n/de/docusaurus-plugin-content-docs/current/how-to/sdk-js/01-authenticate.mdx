# Das JS/TS-SDK authentifizieren

## Wann Sie diese Anleitung verwenden

Sie installieren `@corelink/client` in einem Node.js- oder modernen Bundler-Kontext und
müssen eine beliebige Cache-API aufrufen. Die PAT-Authentifizierung ist zwingend erforderlich; der Client verweigert die
Konstruktion ohne eine solche.

## Voraussetzungen

- Node.js 18+ (verwendet das globale `fetch`) oder ein beliebiger Bundler mit Ziel ES2022. ESM ist die Voreinstellung; `require()` von CommonJS wird nicht unterstützt.
- `npm install @corelink/client`
- Ein unter `https://humangr.com/corelink/tokens` erzeugtes PAT.

## Empfohlene Umgebungsvariable (Node.js)

```bash
export CORELINK_PAT="corelink_dev_t_xxx.xxx.xxx"
```

```typescript
import { CoreLinkClient } from "@corelink/client";

// PAT is read from CORELINK_PAT; the constructor throws if neither the
// `pat` argument nor the env var is present.
const client = new CoreLinkClient({ tenantId: "acme-corp" });

// The first real call surfaces an invalid/revoked PAT as an AuthError (401).
const digest = await client.put(new TextEncoder().encode("ping"));
console.log("authenticated; wrote", digest);
await client.close();
```

## Browser / Bundler

Betten Sie niemals ein PAT in JS ein, das an den Browser ausgeliefert wird. Leiten Sie stattdessen über Ihr eigenes
Backend weiter und übermitteln Sie kurzlebige, pro Benutzer von Ihrem Server erzeugte Token.

```typescript
// frontend
const client = new CoreLinkClient({
  pat: await fetch("/api/corelink-token").then((r) => r.text()),
  tenantId: "acme-corp",
});
```

Der Endpunkt `/api/corelink-token` muss die Sitzung des Endbenutzers validieren und
ein auftragsbezogenes PAT mit den minimal erforderlichen Berechtigungen ausstellen.

## Verboten: PAT im eingecheckten Quellcode

```typescript
// DO NOT DO THIS
const client = new CoreLinkClient({
  pat: "corelink_dev_t_xxx.xxx.xxx",
  tenantId: "acme-corp",
});
```

Verstößt gegen CTRL-CRED-001. Das CI-Lint meldet fest codierte Zeichenketten, die wie ein PAT aussehen.

## Überprüfen

```typescript
import { AuthError } from "@corelink/client";

try {
  // Any authenticated call works; `stat` is cheap and side-effect-free.
  await client.stat("0".repeat(64));
} catch (e) {
  if (e instanceof AuthError) {
    console.error("auth failed:", e.code);
    process.exit(1);
  }
  throw e;
}
```
