# How-to guides

**Task-oriented.** How-to guides assume competence and answer "how do I
do X?". They are recipes, not lessons — they skip context and focus on
the steps.

## Available how-to guides

### Migration

If you have an existing cache or artifact store and want to move to
CoreLink without a lighthouse-style white-glove engagement:

- **[Migration overview](./migrate/index.mdx)** — decision matrix
  + shared pre-flight checklist.
- **[From a Bazel remote cache](./migrate/from-bazel-remote-cache.mdx)** — `bazel-remote`, BuildBuddy, Buck2, Pants.
- **[From S3-only artifact storage](./migrate/from-s3-only.mdx)** — plain object stores; build artifacts, ML datasets, release binaries.
- **[From a Docker registry](./migrate/from-docker-registry.mdx)** — self-hosted Harbor / Quay / `registry:2`.
