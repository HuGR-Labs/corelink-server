# Blob hochladen

## Wann Sie diese Anleitung verwenden

Verwenden Sie dies, wenn Sie beliebige Bytes (ein Build-Ergebnis, ein
Modellgewicht, ein verpacktes Tarball) im CoreLink-CAS speichern müssen und
möchten, dass das SDK den BLAKE3-Digest für Sie berechnet.

Wenn Sie bereits einen Digest haben und die Neuberechnung überspringen möchten,
geben Sie ihn über `expected_digest=` an.

## Voraussetzungen

- Authentifizierung konfiguriert (siehe [01-authenticate](./01-authenticate)).

## Minimalbeispiel

```python
import asyncio
from pathlib import Path
from corelink import AsyncCoreLinkClient

async def main() -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        data = Path("./build/output.tar").read_bytes()
        digest = await client.put(data)
        print(f"stored: {digest}")  # 64-char BLAKE3 hex
```

> Der synchrone Zwilling ist `corelink.CoreLinkClient` — dieselben Methoden ohne
> `async`/`await` (`digest = client.put(data)`), verwendet mit einem einfachen `with`-Block.

## Streaming-Upload (große Blobs)

Verwenden Sie für große Dateien die Streaming-Überladung, um zu vermeiden, dass die
Datei vollständig in den Speicher geladen wird — der BLAKE3-Digest wird in einem
einzigen zurückgespulten Durchlauf über das geöffnete Datei-Handle berechnet, und
anschließend wird dasselbe Handle an den Server gestreamt:

```python
async def upload_large(path: str) -> str:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        with open(path, "rb") as f:
            return await client.put_stream(f, chunk_size=4 * 1024 * 1024)
```

## Idempotenz

`put` ist bezüglich des Digests idempotent. Ein zweiter Upload identischer Bytes
gibt denselben Digest ohne zusätzliche Speicherkosten zurück (CTRL-CAS-001-Dedupe).

## Fehler

| Ausnahme | Ursache | Maßnahme |
|---|---|---|
| `CoreLinkAuthError` | PAT fehlt oder wurde widerrufen (HTTP 401) | Führen Sie [01-authenticate](./01-authenticate) erneut aus |
| `CoreLinkQuotaError` | Tenant über dem Kontingent (HTTP 402) | Prüfen Sie `corelink stat`; siehe [Fehlerbehebung](./07-troubleshooting) |
| `CoreLinkDigestMismatchError` | `expected_digest` stimmte nicht mit `blake3(body)` überein (HTTP 422) | Lokal neu berechnen; nicht blind wiederholen |

Alle werden aus `corelink.exceptions` (oder dem übergeordneten Paket `corelink`)
importiert und sind Unterklassen von `CoreLinkError`.
