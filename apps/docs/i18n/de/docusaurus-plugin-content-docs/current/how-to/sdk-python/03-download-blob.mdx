# Blob herunterladen

## Wann Sie diese Anleitung verwenden

Sie haben einen BLAKE3-Digest (aus einem vorherigen `put`, aus einem
Action-Cache-Ergebnis oder aus Peer-Metadaten) und müssen die Bytes lokal
materialisieren. Das SDK prüft den Hash standardmäßig clientseitig (CTRL-CAS-002).

## Voraussetzungen

- Ein bekannter BLAKE3-Digest.
- Authentifizierung konfiguriert.

## Minimalbeispiel

```python
import asyncio
from corelink import AsyncCoreLinkClient

async def main() -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        digest = "0123456789abcdef" * 4
        data = await client.get(digest)
        # data is already BLAKE3-verified; if verify failed, get() raises.
        with open("./out.bin", "wb") as f:
            f.write(data)
```

> Der synchrone Zwilling ist `corelink.CoreLinkClient` — `data = client.get(digest)`
> unter einem einfachen `with`-Block.

## Streaming-Download

```python
async def stream_to_file(digest: str, dest: str) -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        async with client.get_stream(digest) as stream:
            with open(dest, "wb") as f:
                async for chunk in stream:
                    f.write(chunk)
        # stream.__aexit__ raises if final verify fails.
```

Der Streaming-Prüfer berechnet den Hash inkrementell und validiert die
BLAKE3-Wurzel, sobald der letzte Chunk eintrifft. Stimmt die Wurzel nicht überein,
löst `stream.__aexit__` `CoreLinkDigestMismatchError` aus; das SDK verschiebt die
Datei niemals an ihren endgültigen Platz, sodass das Löschen der teilweisen
Ausgabe in der Verantwortung des Aufrufers liegt.

## Verzicht auf die Prüfung

**Dringend abgeraten**. Der Verzicht existiert nur für Benchmarks, die die reine
Transportlatenz messen müssen. Das Setzen von `verify=False` gibt eine
`WARNING`-Logzeile `corelink.client.verify_disabled` aus, gemäß CTRL-CAS-002.

```python
data = await client.get(digest, verify=False)
```

Wenn Sie versucht sind, zu diesem Flag zu greifen, melden Sie zuerst ein Issue.

## Fehler

| Ausnahme | Bedeutung |
|---|---|
| `CoreLinkNotFoundError` | Der Digest existiert nicht im Tenant-CAS (HTTP 404) oder wurde gelöscht (HTTP 410) |
| `CoreLinkDigestMismatchError` | Bytes wurden während der Übertragung beschädigt; verwenden Sie die Daten nicht |

Alle werden aus `corelink.exceptions` (oder dem übergeordneten Paket `corelink`)
importiert und sind Unterklassen von `CoreLinkError`.
