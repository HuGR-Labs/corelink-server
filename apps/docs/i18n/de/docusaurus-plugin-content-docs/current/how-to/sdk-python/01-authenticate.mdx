# Python-SDK authentifizieren

## Wann Sie diese Anleitung verwenden

Sie haben `corelink-py` installiert und müssen eine API aufrufen, die den Cache
verändert oder liest. Für jede Anfrage außer `corelink.ping` ist ein PAT
erforderlich.

Wenn Sie nur die aktuelle SDK-Version auslesen möchten, siehe
[Fehlerbehebung](./07-troubleshooting).

## Voraussetzungen

- Python 3.10+ (`asyncio` wird von jedem Beispiel in diesem Abschnitt verwendet).
- `pip install corelink-py` (Wheels auf PyPI veröffentlicht; pyO3-Bindings).
- Ein CoreLink-Tenant. Erstellen Sie einen PAT unter `https://humangr.com/corelink/tokens`.

## Empfohlen: Umgebungsvariable

Das SDK liest `CORELINK_PAT` automatisch:

```bash
export CORELINK_PAT="corelink_dev_t_xxx.xxx.xxx"
```

```python
import asyncio
from corelink import CoreLinkClient

async def main() -> None:
    async with CoreLinkClient(tenant_id="acme-corp") as client:
        info = await client.whoami()
        print(info.tenant_id, info.scopes)

asyncio.run(main())
```

Der `with`-Block stellt sicher, dass der zugrunde liegende HTTP/2-Pool sauber
geschlossen wird.

## Alternative: Konfigurationsdatei

Für die lokale Entwicklung legen Sie `~/.corelink/config.toml` an:

```toml
[auth]
pat = "corelink_dev_t_xxx.xxx.xxx"

[defaults]
tenant_id = "acme-corp"
```

Das SDK greift auf diese Datei zurück, wenn `CORELINK_PAT` nicht gesetzt ist.

## Verboten: PAT als Funktionsargument in ausgeliefertem Code

Committen Sie keinen Code, der einen PAT fest einbettet:

```python
# DO NOT DO THIS
client = CoreLinkClient(pat="corelink_dev_t_xxx.xxx.xxx", tenant_id="acme-corp")
```

Dies verstößt gegen CTRL-CRED-001. Verwenden Sie ausschließlich
Umgebungsvariablen oder Konfigurationsdateien.

## Überprüfen

```python
import asyncio
from corelink import CoreLinkClient, AuthError

async def verify() -> None:
    try:
        async with CoreLinkClient() as client:
            await client.whoami()
            print("ok")
    except AuthError as e:
        print(f"auth failed: {e.code}")

asyncio.run(verify())
```

Erwarteter Exit-Code `0` bei Erfolg; `1` bei `AuthError`.
