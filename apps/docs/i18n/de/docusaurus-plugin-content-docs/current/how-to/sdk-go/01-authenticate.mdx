# Go-SDK authentifizieren

## Wann diese Anleitung verwenden

Sie importieren `go.corelink.humangr.com/corelink-go` und müssen eine
cache-verändernde oder cache-lesende API aufrufen. PAT-Authentifizierung
ist verpflichtend; das SDK verweigert die Konstruktion eines Clients ohne
PAT.

## Voraussetzungen

- Go 1.22+.
- `corelink-go` ist ein reines Go-Modul — kein cgo, keine native
  Bibliothek, nichts vorher zu bauen. Beziehen Sie es über CoreLinks
  eigenen Modul-Proxy:

  ```bash
  GOPROXY=https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct go get go.corelink.humangr.com/corelink-go@v0.1.0
  ```

  Die `GOPROXY`-Einstellung ist verpflichtend, kein Nice-to-have:
  `go.corelink.humangr.com` hat keinen DNS-Eintrag, daher schlägt ein
  einfaches `go get` mit „no such host" fehl. Das Modul wird über
  CoreLinks eigenen Proxy ausgeliefert — der erste Eintrag in der Liste.
  Der zweite Eintrag, `https://proxy.golang.org`, holt die gewöhnlichen
  öffentlichen Abhängigkeiten dieses Moduls; `direct` ist der Fallback,
  falls beide Proxys nichts finden.
- Ein CoreLink-Tenant; PAT erstellt unter
  `https://humangr.com/corelink/en/customer/keys`.

## Client konstruieren

```go
package main

import (
    "context"
    "log"
    "os"

    "go.corelink.humangr.com/corelink-go"
)

func main() {
    client, err := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        TenantID: "acme-corp",
    })
    if err != nil {
        log.Fatal(err)
    }
    defer client.Close()

    ctx := context.Background()
    digest, err := client.Put(ctx, []byte("hello"))
    if err != nil {
        log.Fatal(err)
    }
    data, err := client.Get(ctx, digest)
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("wrote+read %d bytes at %s", len(data), digest.Hash)
}
```

`corelink.NewClient` nimmt ein `Config`-Struct entgegen sowie optionale
funktionale Optionen (`corelink.WithTenantID`, um den Tenant getrennt vom
Config-Literal festzulegen). `Config.Endpoint` und `Config.PAT` sind
verpflichtend; `NewClient` liefert einen Fehler, wenn eines der beiden
leer ist. `Config.TenantID` ist im Allgemeinen optional — ein PAT trägt
bereits seinen eigenen Tenant — aber die nativen CAS-Routen
(`Put`/`Get`/`Stat`) benötigen einen, setzen Sie ihn also, sofern Sie
nicht ausschließlich die REAPI-v2-Oberfläche nutzen.

## Verboten: PAT als Struct-Literal in committetem Code

```go
// DO NOT DO THIS
client, _ := corelink.NewClient(corelink.Config{
    Endpoint: "https://corelink-api.humangr.com",
    PAT:      "corelink_pat_0123456789ABCDEF.AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA.BBBBBBBBBBBBBBBBBBBBBA",
    TenantID: "acme-corp",
})
```

Verstößt gegen CTRL-CRED-001. Lesen Sie `Config.PAT` ausschließlich aus
`os.Getenv("CORELINK_PAT")`.

## Verifizieren

Dieser Client hat keine `Whoami`-Methode. `NewClient` selbst validiert
nur die Struktur der Config und führt keine Netzwerk-I/O aus; ein
ungültiger oder widerrufener PAT tritt erst beim ersten tatsächlichen
Aufruf von `Put`/`Get`/`Stat` als typisierter `*corelink.AuthError` zutage:

```go
digest, err := client.Put(ctx, []byte("healthcheck"))
if err != nil {
    var authErr *corelink.AuthError
    if errors.As(err, &authErr) {
        log.Fatalf("auth failed (%d): %s", authErr.StatusCode, authErr.Message)
    }
    log.Fatalf("request failed: %v", err)
}
log.Println("authenticated; wrote", digest.Hash)
```

## Self-service PAT issuance

Authenticated tenants can issue an additional PAT with `POST /v1/pats`;
`POST /v1/customer/keys` is the compatible dashboard alias. Both routes use
the same per-tenant `pat-issue` limiter (burst 10, then 10/hour, one token
every 360 seconds), enforced before mint and audit. Handle `429` and its
`Retry-After` header; the plaintext token is returned only once.
