# CI-Integration

## Wann diese Anleitung verwenden

Ihr Build ist ein Go-Projekt (oder seine Smoke-Tests sind in Go
geschrieben) und Sie wollen CoreLink als geteilten Cache nutzen, ohne
die CLI aufzurufen.

## GitHub Actions

```yaml
# .github/workflows/build.yml
jobs:
  build:
    runs-on: ubuntu-latest
    env:
      CORELINK_PAT: ${{ secrets.CORELINK_PAT }}
      GOPROXY: https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: "1.22"
      - run: go get go.corelink.humangr.com/corelink-go@v0.1.0  # GOPROXY oben gesetzt
      - run: go run ./ci/warm-cache
```

```go
// ci/warm-cache/main.go
package main

import (
    "context"
    "log"
    "os"

    "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    cli, err := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        TenantID: os.Getenv("CORELINK_TENANT"),
    })
    if err != nil {
        log.Fatal(err)
    }
    defer cli.Close()

    // Wärmen Sie den Cache mit einem echten Put/Get-Roundtrip auf und
    // lassen Sie den Job bei einem Fehler fehlschlagen.
    digest, err := cli.Put(ctx, []byte("ci-warm-cache-probe"))
    if err != nil {
        log.Fatalf("cache warm-up failed: %v", err)
    }
    if _, err := cli.Get(ctx, digest); err != nil {
        log.Fatalf("cache verify failed: %v", err)
    }
    log.Println("cache reachable")
}
```

## GitLab CI

```yaml
build:
  image: golang:1.22
  variables:
    CORELINK_PAT: $CORELINK_PAT  # masked
    GOPROXY: "https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct"
  script:
    - go get go.corelink.humangr.com/corelink-go@v0.1.0  # GOPROXY oben gesetzt
    - go run ./ci/warm-cache
```

## CircleCI

```yaml
version: 2.1
jobs:
  build:
    docker:
      - image: cimg/go:1.22
    environment:
      CORELINK_PAT: $CORELINK_PAT
      GOPROXY: https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct
    steps:
      - checkout
      - run: go get go.corelink.humangr.com/corelink-go@v0.1.0  # GOPROXY oben gesetzt
      - run: go run ./ci/warm-cache
```

## Job-gebundene PATs

Es gibt heute keine Self-Service-API, um pro Pipeline einen kurzlebigen
PAT zu erstellen (siehe [Security model](../../security.md)) — schreiben
Sie an [support@humangr.com](mailto:support@humangr.com), um einen
dedizierten CI-PAT anzufordern, und binden Sie ihn dann wie oben gezeigt
über den Secret-Store Ihres CI-Anbieters ein.
