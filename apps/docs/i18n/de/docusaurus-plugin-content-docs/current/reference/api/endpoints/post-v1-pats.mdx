# `POST` `/v1/pats`

> Issue a new Personal Access Token.

- **Operation ID:** `patIssue`
- **Tag:** `pat`
- **Rate-limit class:** pat-issue (10 req/hour/tenant)

This endpoint and the legacy dashboard alias \`POST /v1/customer/keys\` use
the same customer-plane mint flow and the same per-tenant \`pat-issue\` bucket:
burst 10, then 10 tokens per hour (one every 360 seconds). The limiter runs
before mint and audit; a denied request returns \`429\` with \`Retry-After\`.

## Description

Creates a PAT for the caller's authenticated tenant. The Worker derives
the tenant from a validated Clerk session or canonical PAT; clients
cannot supply a tenant id and this endpoint never accepts the
operator-only mint authority. The raw token is returned exactly once in
`token` and is never logged or retrievable later. Self-service tokens
expire after 90 days and cannot grant `admin`.

## Authentication

- `BearerPAT`
- `ClerkSessionCookie`
