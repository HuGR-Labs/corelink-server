# Python — `Capabilities.GetCapabilities`

Discover server-side limits (max batch size, digest functions, compressors) before issuing CAS writes.

## Prerequisites

- `pip install corelink-py`
- `CORELINK_PAT` exported

## Code

```python
import asyncio, os
from corelink import CoreLinkClient

async def main() -> None:
    async with CoreLinkClient(
        endpoint="https://corelink-api.humangr.com",
        pat=os.environ["CORELINK_PAT"],
    ) as client:
        caps = await client.capabilities.get()
        cc = caps.cache_capabilities
        print(f"max_batch_total_size_bytes = {cc.max_batch_total_size_bytes}")
        print(f"digest functions = {[df.name for df in cc.digest_functions]}")
        print(f"compressors = {[c.name for c in cc.supported_compressors]}")

asyncio.run(main())
```

## Expected output

```text
max_batch_total_size_bytes = 4194304
digest functions = ['SHA256', 'BLAKE3']
compressors = ['IDENTITY', 'ZSTD']
```
