# Node / TypeScript — `Health.Check`

## Code

```ts
import { CoreLinkClient } from "@corelink/client";

const client = new CoreLinkClient({
  endpoint: "https://acme-dev.corelink.dev",
  pat: process.env.CORELINK_PAT!,
});

const status = await client.health.check();
console.log(`server status = ${status}`);
if (status !== "SERVING") process.exit(1);
```

## Expected output

```text
server status = SERVING
```

## Common errors

| Status | Error taxonomy | Cause |
| --- | --- | --- |
| `UNAVAILABLE` | `COR_NET_TRANSIENT` | Server restarting; retry. |
| `NOT_SERVING` | `COR_HEALTH_NOT_SERVING` | Drain — reconnect to another region. |
