# Go — eine Digest-Funktion wählen

Es gibt keinen `Capabilities`-Endpoint, gegen den eine Digest-Funktion
ausgehandelt werden könnte (siehe [GetCapabilities](./go-get-capabilities.mdx)).
Wählen Sie stattdessen explizit eine: `corelink.DigestBLAKE3` ist der
CAS-Standard und die einzige Funktion, die die native
`/v1/cas`-Oberfläche akzeptiert; verwenden Sie `corelink.DigestSHA256`
nur, wenn Sie wissen, dass die REAPI-Instanz, mit der Sie sprechen, sie
erwartet.

## Code

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Digest:   corelink.DigestBLAKE3,
    })
    defer client.Close()

    // Switch at runtime if a particular call needs SHA-256 instead.
    client.SetDigestFunction(corelink.DigestSHA256)
    fmt.Println("using SHA-256 for this call")

    _ = ctx
}
```

## Erwartete Ausgabe

```text
using SHA-256 for this call
```
