# Go — `BatchReadBlobs`

Viele kleine Blobs mit standardmäßig aktiviertem Client-Verify lesen.
Der Server hat keine Batch-Read-REAPI-Route, daher setzt `BatchRead`
pro Digest ein GET ab und verifiziert jeden Blob, bevor er ihn
zurückgibt — es ist ein Convenience-Wrapper, kein einzelner Roundtrip.

## Voraussetzungen

```bash
GOPROXY=https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct go get go.corelink.humangr.com/corelink-go@v0.1.0
```

- `CORELINK_PAT` exportiert

## Code

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, err := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Instance: "default",
    })
    if err != nil {
        panic(err)
    }
    defer client.Close()

    digests := []corelink.Digest{
        {Hash: "bdd9ea4a8e6b...", SizeBytes: 5},
        {Hash: "71c8b65b8b7e...", SizeBytes: 4},
    }
    blobs, err := client.CAS().BatchRead(ctx, digests)
    if err != nil {
        panic(err)
    }
    for d, data := range blobs {
        fmt.Printf("OK %s (%d B)\n", d.Hash[:12], len(data))
    }
}
```

## Erwartete Ausgabe

```text
OK bdd9ea4a8e6b (5 B)
OK 71c8b65b8b7e (4 B)
```

## Häufige Fehler

| Fehlertyp | Ursache |
| --- | --- |
| `*corelink.NotFoundError` | Digest nicht vorhanden (oder evicted). |
| `*corelink.DigestMismatchError` | Client-Verify hat zurückgegebene Bytes abgelehnt. |
