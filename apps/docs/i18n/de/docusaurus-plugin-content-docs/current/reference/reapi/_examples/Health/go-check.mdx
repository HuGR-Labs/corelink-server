# Go — `Health.Check`

## Code

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
    })
    defer client.Close()

    status, err := client.Health(ctx)
    if err != nil { panic(err) }
    fmt.Println("server ok =", status.OK)
}
```

## Erwartete Ausgabe

```text
server ok = true
```

## Häufige Fehler

| Fehlertyp | Ursache |
| --- | --- |
| einfacher Fehler (Netzwerk) | Server nicht erreichbar oder startet neu. Erneut versuchen. |
| `*corelink.AuthError` | PAT abgelehnt. |
