# Upload a blob

## When to use this guide

You have a file on disk and want to push it into the tenant CAS from a
shell — interactively or from a CI job script.

## Prerequisites

- Authentication configured ([01-authenticate](./01-authenticate.mdx)).

## Minimal command

```bash
corelink put ./build/output.tar
# stdout: 64-char BLAKE3 hex digest
```

The CLI computes the BLAKE3 digest locally before transmission. If a
matching digest already exists server-side, the upload short-circuits.

## Pre-computed digest

```bash
DIGEST=$(b3sum ./build/output.tar | awk '{print $1}')
corelink put ./build/output.tar --digest "$DIGEST"
```

`--digest` is not checked client-side against the file bytes — the CLI
uploads the claim as-is and the server re-hashes and rejects a wrong claim
with `422`. A wrong `--digest` therefore fails with exit code `1` and an
`error: cas_put: HTTP 422 ...` message — re-run without `--digest` to let
the CLI compute it for you.

## JSON output

```bash
corelink put ./out.tar --output json
```

```json
{
  "ok": true,
  "subcommand": "put",
  "digest": "0123...cdef",
  "size_bytes": 1048576,
  "duplicate": false
}
```

Schema documented in [reference/cli/put](../../reference/cli/put.mdx).

## Bulk uploads

`put` is single-file by design. For batch loads, drive it from a shell loop
with bounded concurrency:

```bash
find ./outputs -type f -print0 \
  | xargs -0 -n1 -P 32 corelink put --output json \
  | jq -r '.digest' > digests.txt
```

`-P 32` is a safe default; server allows up to `256` per PAT.

## Exit codes

The CLI has exactly four exit codes, shared by every subcommand (per
`tools/cli/src/main.rs`):

| Code | Meaning |
|---|---|
| `0` | Success |
| `1` | Any command failure — network, auth, quota, digest mismatch, unreadable file, HTTP error, and so on. There is no finer-grained taxonomy; read the `error: ...` message on stderr. |
| `2` | Argument/flag error (clap parse failure), or the `--pat` flag was rejected (CTRL-CRED-001 — PATs must come from `CORELINK_PAT` or the config file, never a CLI arg) |
| `65` | Reserved for `corelink audit verify-ndjson --url` mid-stream integrity abort only — not used by `put`/`get` |
