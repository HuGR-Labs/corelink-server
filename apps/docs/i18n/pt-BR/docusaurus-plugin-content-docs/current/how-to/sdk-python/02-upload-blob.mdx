# Enviar um blob

## Quando usar este guia

Use isto quando precisar persistir bytes arbitrários (uma saída de build, um peso
de modelo, um tarball empacotado) no CAS do CoreLink e quiser que o SDK calcule o
digest BLAKE3 para você.

Se você já tem um digest e quer pular o recálculo, forneça-o via
`expected_digest=`.

## Pré-requisitos

- Autenticação configurada (consulte [01-authenticate](./01-authenticate)).

## Exemplo mínimo

```python
import asyncio
from pathlib import Path
from corelink import AsyncCoreLinkClient

async def main() -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        data = Path("./build/output.tar").read_bytes()
        digest = await client.put(data)
        print(f"stored: {digest}")  # 64-char BLAKE3 hex
```

> O gêmeo síncrono é `corelink.CoreLinkClient` — os mesmos métodos sem
> `async`/`await` (`digest = client.put(data)`), usados com um bloco `with` simples.

## Upload em streaming (blobs grandes)

Para arquivos grandes, use a sobrecarga de streaming para evitar carregar o
arquivo inteiro na memória — o digest BLAKE3 é calculado em uma única passagem
rebobinada sobre o handle de arquivo aberto, e então o mesmo handle é transmitido
ao servidor:

```python
async def upload_large(path: str) -> str:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        with open(path, "rb") as f:
            return await client.put_stream(f, chunk_size=4 * 1024 * 1024)
```

## Idempotência

`put` é idempotente em relação ao digest. Um segundo upload de bytes idênticos
retorna o mesmo digest sem custo adicional de armazenamento (dedupe CTRL-CAS-001).

## Erros

| Exceção | Causa | Ação |
|---|---|---|
| `CoreLinkAuthError` | PAT ausente ou revogado (HTTP 401) | Execute novamente [01-authenticate](./01-authenticate) |
| `CoreLinkQuotaError` | Tenant acima da cota (HTTP 402) | Inspecione `corelink stat`; consulte [solução de problemas](./07-troubleshooting) |
| `CoreLinkDigestMismatchError` | `expected_digest` não correspondeu a `blake3(body)` (HTTP 422) | Recalcule localmente; não repita cegamente |

Todas são importadas de `corelink.exceptions` (ou do pacote de nível superior
`corelink`) e são subclasses de `CoreLinkError`.
