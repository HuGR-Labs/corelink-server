# Authenticate the Python SDK

## When to use this guide

You have installed `corelink-py` and need to call any cache-mutating or
cache-reading API. A PAT is required for every CAS call.

## Prerequisites

- `pip install corelink-py` (wheels published on PyPI).
- A CoreLink tenant. Issue a PAT at `https://humangr.com/corelink/en/customer/keys`.

## Two clients: sync and async

`corelink-py` ships **two separate client classes** — pick the one that
matches your code, they are not interchangeable:

- `corelink.client.CoreLinkClient` — **synchronous**. Supports `with` (not
  `async with`).
- `corelink.aio.AsyncCoreLinkClient` — **asynchronous**, built on
  `httpx.AsyncClient`. Supports `async with` / `await`.

## Recommended: Env var

Both clients read `CORELINK_PAT` automatically if you don't pass `pat=`
explicitly:

```bash
export CORELINK_PAT="corelink_pat_01ARZ3NDEKTSV4RRFFQ69G5FAV.4pT7q1yZ9vX2wL8cR5nB3sD6fH0jK1mQ8aV2eS.7bY4tN9oL2x"
```

Async example (`AsyncCoreLinkClient`):

```python
import asyncio
from corelink import AsyncCoreLinkClient

async def main() -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        digest = await client.put(b"hello world")
        data = await client.get(digest)
        print(digest, len(data))

asyncio.run(main())
```

Sync example (`CoreLinkClient`, no `asyncio` needed):

```python
from corelink.client import CoreLinkClient

with CoreLinkClient(tenant_id="acme-corp") as client:
    digest = client.put(b"hello world")
    data = client.get(digest)
    print(digest, len(data))
```

The `with` / `async with` block ensures the underlying HTTP connection pool
is closed cleanly.

There is no `whoami()` method on either client — to confirm a PAT is valid,
any authenticated call works (`put`/`get`/`stat` are cheap and
side-effect-free for a small test payload).

## Alternative: Config file

For local development, write `~/.corelink/config.toml`:

```toml
[auth]
pat = "corelink_pat_01ARZ3NDEKTSV4RRFFQ69G5FAV.4pT7q1yZ9vX2wL8cR5nB3sD6fH0jK1mQ8aV2eS.7bY4tN9oL2x"

[defaults]
tenant_id = "acme-corp"
```

The SDK falls back to this file if `CORELINK_PAT` is not set.

## Forbidden: PAT as a function argument in shipped code

Do not commit code that hard-codes a PAT:

```python
# DO NOT DO THIS
client = CoreLinkClient(pat="corelink_pat_01ARZ3NDEKTSV4RRFFQ69G5FAV.4pT7q1yZ9vX2wL8cR5nB3sD6fH0jK1mQ8aV2eS.7bY4tN9oL2x", tenant_id="acme-corp")
```

This violates CTRL-CRED-001. Use env vars or config files only.

## Verify

```python
from corelink.client import CoreLinkClient
from corelink.exceptions import CoreLinkAuthError

def verify() -> None:
    try:
        with CoreLinkClient() as client:
            client.stat("0" * 64)  # cheap, side-effect-free authenticated call
            print("ok")
    except CoreLinkAuthError:
        print("auth failed: PAT missing or invalid")
        raise

verify()
```

Any `CoreLinkAuthError` means the PAT is missing or invalid (the server
returned `401`).
