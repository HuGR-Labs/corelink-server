# Autenticar o SDK Python

## Quando usar este guia

Você instalou o `corelink-py` e precisa chamar qualquer API que altere ou leia o
cache. Um PAT é obrigatório em todas as requisições, exceto `corelink.ping`.

Se você só precisa ler a versão atual do SDK, consulte
[Solução de problemas](./07-troubleshooting.mdx).

## Pré-requisitos

- Python 3.10+ (`asyncio` é usado por todos os exemplos desta seção).
- `pip install corelink-py` (wheels publicados no PyPI; bindings pyO3).
- Um tenant CoreLink. Emita um PAT em `https://humangr.com/corelink/tokens`.

## Recomendado: variável de ambiente

O SDK lê `CORELINK_PAT` automaticamente:

```bash
export CORELINK_PAT="corelink_dev_t_xxx.xxx.xxx"
```

```python
import asyncio
from corelink import CoreLinkClient

async def main() -> None:
    async with CoreLinkClient(tenant_id="acme-corp") as client:
        info = await client.whoami()
        print(info.tenant_id, info.scopes)

asyncio.run(main())
```

O bloco `with` garante que o pool HTTP/2 subjacente seja fechado corretamente.

## Alternativa: arquivo de configuração

Para desenvolvimento local, crie `~/.corelink/config.toml`:

```toml
[auth]
pat = "corelink_dev_t_xxx.xxx.xxx"

[defaults]
tenant_id = "acme-corp"
```

O SDK recorre a esse arquivo se `CORELINK_PAT` não estiver definido.

## Proibido: PAT como argumento de função em código publicado

Não faça commit de código que embuta um PAT diretamente:

```python
# DO NOT DO THIS
client = CoreLinkClient(pat="corelink_dev_t_xxx.xxx.xxx", tenant_id="acme-corp")
```

Isso viola CTRL-CRED-001. Use apenas variáveis de ambiente ou arquivos de
configuração.

## Verificar

```python
import asyncio
from corelink import CoreLinkClient, AuthError

async def verify() -> None:
    try:
        async with CoreLinkClient() as client:
            await client.whoami()
            print("ok")
    except AuthError as e:
        print(f"auth failed: {e.code}")

asyncio.run(verify())
```

Código de saída esperado `0` em caso de sucesso; `1` em `AuthError`.
