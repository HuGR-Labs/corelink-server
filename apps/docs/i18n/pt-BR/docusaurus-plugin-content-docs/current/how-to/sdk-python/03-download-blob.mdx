# Baixar um blob

## Quando usar este guia

Você tem um digest BLAKE3 (de um `put` anterior, de um resultado do Action Cache
ou de metadados de um peer) e precisa materializar os bytes localmente. O SDK
verifica o hash do lado do cliente por padrão (CTRL-CAS-002).

## Pré-requisitos

- Um digest BLAKE3 conhecido.
- Autenticação configurada.

## Exemplo mínimo

```python
import asyncio
from corelink import AsyncCoreLinkClient

async def main() -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        digest = "0123456789abcdef" * 4
        data = await client.get(digest)
        # data is already BLAKE3-verified; if verify failed, get() raises.
        with open("./out.bin", "wb") as f:
            f.write(data)
```

> O gêmeo síncrono é `corelink.CoreLinkClient` — `data = client.get(digest)`
> dentro de um bloco `with` simples.

## Download em streaming

```python
async def stream_to_file(digest: str, dest: str) -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        async with client.get_stream(digest) as stream:
            with open(dest, "wb") as f:
                async for chunk in stream:
                    f.write(chunk)
        # stream.__aexit__ raises if final verify fails.
```

O verificador de streaming calcula o hash de forma incremental e valida a raiz
BLAKE3 assim que o último chunk chega. Se a raiz não corresponder,
`stream.__aexit__` levanta `CoreLinkDigestMismatchError`; o SDK nunca move o
arquivo para o lugar final, então excluir a saída parcial é responsabilidade do
chamador.

## Desativar a verificação

**Fortemente desaconselhado**. A desativação existe apenas para benchmarks que
precisam medir a latência bruta de transporte. Definir `verify=False` emite uma
linha de log `WARNING` `corelink.client.verify_disabled`, conforme CTRL-CAS-002.

```python
data = await client.get(digest, verify=False)
```

Se você se pegar tentado a usar essa flag, abra uma issue primeiro.

## Erros

| Exceção | Significado |
|---|---|
| `CoreLinkNotFoundError` | O digest não existe no CAS do tenant (HTTP 404), ou foi apagado (HTTP 410) |
| `CoreLinkDigestMismatchError` | Bytes corrompidos no transporte; não use os dados |

Todas são importadas de `corelink.exceptions` (ou do pacote de nível superior
`corelink`) e são subclasses de `CoreLinkError`.
