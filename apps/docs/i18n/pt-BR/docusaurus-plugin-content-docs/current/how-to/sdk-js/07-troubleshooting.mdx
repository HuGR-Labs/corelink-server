# Solução de problemas

## Quando usar este guia

Uma chamada de `@corelink/client` está lançando exceção ou travando. Todo erro estende
`CoreLinkError` e carrega um `status` (status HTTP, quando originado no servidor)
e um `code` curto (a string de motivo do servidor). Inspecione-os:

## Fluxo de diagnóstico

```typescript
import { CoreLinkError } from "@corelink/client";

try {
  await client.get(digest);
} catch (e) {
  if (e instanceof CoreLinkError) {
    console.error(`${e.name} status=${e.status} code=${e.code}: ${e.message}`);
  }
  throw e;
}
```

## Erros comuns

Mapeie a classe lançada para sua causa e correção:

| Classe | Status | Primeira ação |
|---|---|---|
| `AuthError` | 401 | Reexporte `CORELINK_PAT`; se revogada, gere uma nova PAT. |
| `ForbiddenError` | 403 | Tenant errado, ou a PAT não tem o escopo de cache necessário. |
| `QuotaError` | 402 | Tenant acima do seu limite de armazenamento / teto de gastos. |
| `NotFoundError` / `ActionCacheMiss` | 404 | Digest / action não armazenado para este tenant. |
| `GoneError` | 410 | O artefato foi apagado (GDPR/DSR); ele não retornará. |
| `DigestMismatchError` | 422 / verify | Descarte os bytes; refaça o download ou o upload. |
| `RateLimitError` | 429 | Nova tentativa automática; se ainda aparecer, reduza a concorrência. |
| `ServerError` | 5xx | Falha transitória no backend; tente novamente com backoff. |
| `ConnectError` | — | Falha de transporte; verifique a rede / `baseUrl`. |

## Sem etapa de build nativa ou WASM

`@corelink/client` é JavaScript puro (BLAKE3 via `@noble/hashes`). Não há artefato
`.wasm` para empacotar e nenhuma regra de asset de bundler para configurar — se você encontrar um
erro de resolução, trata-se de um problema comum de resolução de pacote ESM, não de WASM.

## Ciclo de vida

`close()` hoje é uma operação sem efeito (o SDK usa o `fetch` da plataforma e não mantém
pool persistente), mas chame-o mesmo assim para que seu código continue correto se uma versão
futura adicionar pooling:

```typescript
const client = new CoreLinkClient({ tenantId: "acme-corp" });
try {
  await client.get(digest);
} finally {
  await client.close();
}
```

## Log detalhado

```bash
export CORELINK_LOG=debug
```

Logs JSON estruturados vão para `stderr`. Encaminhe por `jq`:

```bash
node ./script.mjs 2>&1 | jq 'select(.level=="error")'
```

## Como reportar um bug

Inclua a saída de `corelink doctor --json`. Nunca inclua sua PAT.
