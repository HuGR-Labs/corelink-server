# Enviar um blob

## Quando usar este guia

Você tem um `Uint8Array` ou um `Buffer` do Node (que é um `Uint8Array`) e quer que ele seja
persistido no CAS do CoreLink. O SDK calcula o digest BLAKE3 para você; você
pode, opcionalmente, passar um `expectedDigest` para afirmar que ele corresponde localmente.

## Pré-requisitos

- Autenticação configurada ([01-authenticate](./01-authenticate.mdx)).

## Exemplo mínimo

```typescript
import { CoreLinkClient } from "@corelink/client";
import { readFile } from "node:fs/promises";

const client = new CoreLinkClient({ tenantId: "acme-corp" });
const data = await readFile("./build/output.tar");
const digest = await client.put(data);
console.log("stored:", digest);
await client.close();
```

`digest` é a string hexadecimal BLAKE3 de 64 caracteres.

## Blobs grandes

`put` recebe o array de bytes completo (um armazenamento endereçável por conteúdo precisa fazer o
hash do objeto inteiro para saber seu endereço, então o digest é calculado sobre o buffer
completo). Leia o arquivo na memória e depois faça o upload:

```typescript
import { readFile } from "node:fs/promises";

async function uploadLarge(path: string): Promise<string> {
  const data = await readFile(path); // Buffer is a Uint8Array
  return client.put(data);
}
```

Uma API de upload em partes/streaming não faz parte desta versão.

## Idempotência

`put` deduplica no servidor; dois uploads de bytes idênticos resolvem para
o mesmo digest sem cobrança duplicada.

## Tipos TypeScript

O pacote inclui declarações `.d.ts` completas:

```typescript
import type { BlobDigest, TenantId, PutOptions } from "@corelink/client";

const opts: PutOptions = { expectedDigest: "..." satisfies BlobDigest };
```

| Classe | Causa | Ação |
