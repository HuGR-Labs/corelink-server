# Baixar um blob

## Quando usar este guia

Você tem um digest BLAKE3 e precisa dos bytes. O SDK verifica o digest
no lado do cliente (`@noble/hashes`, em JS puro) por padrão (CTRL-CAS-002).

## Pré-requisitos

- Um digest BLAKE3 conhecido.
- Autenticação configurada.

## Exemplo mínimo

```typescript
const data: Uint8Array = await client.get(digest);
// Already BLAKE3-verified; if verify failed, get() threw.
```

## Baixar para um arquivo

`get` retorna todo o `Uint8Array` verificado; grave-o:

```typescript
import { writeFile } from "node:fs/promises";

async function getToFile(digest: string, dest: string): Promise<void> {
  const data = await client.get(digest); // throws DigestMismatchError if corrupt
  await writeFile(dest, data);
}
```

Uma API de download em partes/streaming não faz parte desta versão.

## Desativar a verificação

**Fortemente desaconselhado**. A desativação existe apenas para benchmarks de transporte.
Desative globalmente na construção (`clientVerify: false` — registra
`corelink.client.verify_disabled` conforme CTRL-CAS-002), ou por chamada:

```typescript
const data = await client.get(digest, { verify: false });
```

## Erros

| Classe | Significado |
|---|---|
| `NotFoundError` | Digest não está no CAS do tenant (404) |
| `GoneError` | Artefato apagado (410); não ressuscite |
| `DigestMismatchError` | Bytes corrompidos; não use |
