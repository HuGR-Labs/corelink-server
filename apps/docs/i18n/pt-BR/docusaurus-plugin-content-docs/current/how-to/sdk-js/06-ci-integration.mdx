# Integração com CI

## Quando usar este guia

Seu pipeline de build roda Node.js e você quer o CoreLink como um cache compartilhado
sem invocar o binário da CLI.

## GitHub Actions

```yaml
# .github/workflows/build.yml
jobs:
  build:
    runs-on: ubuntu-latest
    env:
      CORELINK_PAT: ${{ secrets.CORELINK_PAT }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: "20"
      - run: npm ci
      - run: node ./ci/warm-cache.mjs
```

```typescript
// ci/warm-cache.mjs
import { CoreLinkClient } from "@corelink/client";

const client = new CoreLinkClient({ tenantId: process.env.CORELINK_TENANT });
try {
  // A tiny put/get round-trip proves connectivity + auth before the build runs.
  const probe = new TextEncoder().encode(`warm ${Date.now()}`);
  const t0 = performance.now();
  const digest = await client.put(probe);
  await client.get(digest); // BLAKE3-verified
  const ms = performance.now() - t0;
  console.log(`cache reachable; round-trip=${ms.toFixed(1)}ms digest=${digest}`);
  if (ms > 500) console.warn("cache round-trip slower than 500ms");
} finally {
  await client.close();
}
```

## GitLab CI

```yaml
build:
  image: node:22
  variables:
    CORELINK_PAT: $CORELINK_PAT  # masked CI variable
  script:
    - npm ci
    - node ./ci/warm-cache.mjs
```

## CircleCI

```yaml
version: 2.1
jobs:
  build:
    docker:
      - image: cimg/node:22.11
    environment:
      CORELINK_PAT: $CORELINK_PAT
    steps:
      - checkout
      - run: npm ci
      - run: node ./ci/warm-cache.mjs
```
