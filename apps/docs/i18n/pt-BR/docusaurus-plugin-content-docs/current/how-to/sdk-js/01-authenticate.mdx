# Authenticate the JS/TS SDK

## When to use this guide

You install `@corelink/client` in a Node.js or modern bundler context and
need to call any cache API. PAT auth is mandatory; the client refuses to
construct without one.

## Prerequisites

- Node.js 22+ (LTS até 2027-04-30) ou qualquer bundler que mire ES2022. ESM é o padrão; `require()` (CommonJS) está deprecado para novo código de tenants.
- `npm install @corelink/client`
- A PAT minted at `https://app.corelink.humangr.com/tokens`.

## Recommended: env var (Node.js)

```bash
export CORELINK_PAT="corelink_dev_t_xxx.xxx.xxx"
```

```typescript
import { CoreLinkClient } from "@corelink/client";

const client = new CoreLinkClient({ tenantId: "acme-corp" });
const me = await client.whoami();
console.log(me.tenantId, me.scopes);
await client.close();
```

## Browser / bundler

Never embed a PAT in browser-shipped JS. Instead, proxy through your own
backend and forward short-lived per-user tokens minted by your server.

```typescript
// frontend
const client = new CoreLinkClient({
  pat: await fetch("/api/corelink-token").then((r) => r.text()),
  tenantId: "acme-corp",
});
```

The `/api/corelink-token` endpoint must validate the end-user session and
issue a job-scoped PAT with the minimum scopes required.

## Forbidden: PAT in committed source

```typescript
// DO NOT DO THIS
const client = new CoreLinkClient({
  pat: "corelink_dev_t_xxx.xxx.xxx",
  tenantId: "acme-corp",
});
```

Violates CTRL-CRED-001. CI lint flags hard-coded PAT-looking strings.

## Verify

```typescript
import { AuthError } from "@corelink/client";

try {
  await client.whoami();
} catch (e) {
  if (e instanceof AuthError) {
    console.error("auth failed:", e.code);
    process.exit(1);
  }
  throw e;
}
```
