# Autenticar o SDK JS/TS

## Quando usar este guia

Você instala `@corelink/client` em um contexto Node.js ou em um bundler moderno e
precisa chamar qualquer API de cache. A autenticação por PAT é obrigatória; o cliente se recusa a
ser construído sem uma.

## Pré-requisitos

- Node.js 18+ (usa o `fetch` global) ou qualquer bundler que tenha como alvo ES2022. ESM é o padrão; `require()` do CommonJS não é suportado.
- `npm install @corelink/client`
- Uma PAT gerada em `https://humangr.com/corelink/en/customer/keys`.

## Variável de ambiente recomendada (Node.js)

```bash
export CORELINK_PAT="corelink_dev_t_xxx.xxx.xxx"
```

```typescript
import { CoreLinkClient } from "@corelink/client";

// PAT is read from CORELINK_PAT; the constructor throws if neither the
// `pat` argument nor the env var is present.
const client = new CoreLinkClient({ tenantId: "acme-corp" });

// The first real call surfaces an invalid/revoked PAT as an AuthError (401).
const digest = await client.put(new TextEncoder().encode("ping"));
console.log("authenticated; wrote", digest);
await client.close();
```

## Navegador / bundler

Nunca incorpore uma PAT no JS entregue ao navegador. Em vez disso, faça proxy pelo seu próprio
backend e encaminhe tokens de curta duração por usuário gerados pelo seu servidor.

```typescript
// frontend
const client = new CoreLinkClient({
  pat: await fetch("/api/corelink-token").then((r) => r.text()),
  tenantId: "acme-corp",
});
```

O endpoint `/api/corelink-token` deve validar a sessão do usuário final e
emitir uma PAT com escopo de tarefa contendo os escopos mínimos necessários.

## Proibido: PAT no código-fonte versionado

```typescript
// DO NOT DO THIS
const client = new CoreLinkClient({
  pat: "corelink_dev_t_xxx.xxx.xxx",
  tenantId: "acme-corp",
});
```

Viola o CTRL-CRED-001. O lint da CI sinaliza strings com aparência de PAT codificadas diretamente no código.

## Verificar

```typescript
import { AuthError } from "@corelink/client";

try {
  // Any authenticated call works; `stat` is cheap and side-effect-free.
  await client.stat("0".repeat(64));
} catch (e) {
  if (e instanceof AuthError) {
    console.error("auth failed:", e.code);
    process.exit(1);
  }
  throw e;
}
```
