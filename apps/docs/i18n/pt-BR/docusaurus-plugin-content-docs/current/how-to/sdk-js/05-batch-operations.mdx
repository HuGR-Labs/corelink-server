# Operações em lote

## Quando usar este guia

Você tem muitos blobs para enviar ou baixar e quer saturar a largura de banda
disponível sem exceder o limite por PAT do lado do servidor (256 simultâneos).

## Padrão: `Promise.all` limitado

```typescript
import pLimit from "p-limit";
import { readFile } from "node:fs/promises";

async function uploadMany(
  paths: string[],
  concurrency = 32,
): Promise<string[]> {
  const limit = pLimit(concurrency);
  return Promise.all(
    paths.map((p) =>
      limit(async () => {
        const data = await readFile(p);
        return client.put(data);
      }),
    ),
  );
}
```

## Tratamento de limite de taxa

`RateLimitError` (429) e 503 têm nova tentativa automática com backoff exponencial +
jitter (3 tentativas por padrão, cada backoff limitado a `maxDelayMs`). Personalize:

```typescript
const client = new CoreLinkClient({
  tenantId: "acme-corp",
  retry: { maxAttempts: 5, baseDelayMs: 200, maxDelayMs: 10_000 },
});
```

Quando as tentativas se esgotam, drene o trabalho pendente e pare de enviar.

## Padrão: deduplicação indexada por digest

```typescript
import { blake3Hex } from "@corelink/client";

async function uploadDedup(
  paths: string[],
): Promise<Record<string, string>> {
  const seen: Record<string, string> = {};
  for (const p of paths) {
    const data = await readFile(p);
    const hex = blake3Hex(data); // same digest the server addresses the blob by
    if (hex in seen) continue;
    seen[hex] = await client.put(data, { expectedDigest: hex });
  }
  return seen;
}
```

Reduz a contagem de uploads em 60-90% em saídas de build típicas.
