# Upload a blob

## Quando usar este guia

Você tem um `[]byte` e quer persisti-lo no CAS do CoreLink. `Put`
calcula o digest BLAKE3 para você — não há como fornecer um
digest pré-computado do lado do cliente neste SDK (diferente do
`expected_digest=` do `corelink-py`).

## Pré-requisitos

- Autenticação configurada ([01-authenticate](./01-authenticate.mdx)).

## Exemplo mínimo

```go
import (
    "context"
    "os"

    "go.corelink.humangr.com/corelink-go"
)

func upload(ctx context.Context, cli *corelink.Client, path string) (string, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        return "", err
    }
    digest, err := cli.Put(ctx, data)
    if err != nil {
        return "", err
    }
    return digest.Hash, nil
}
```

## Sem upload em streaming na superfície nativa do CAS

`Client` tem exatamente três métodos do CAS nativo — `Put`, `Get`, `Stat` —
e `Put` recebe um `[]byte`, não um `io.Reader`; não há `PutStream` nem
opção de tamanho de chunk nessa superfície. Para um arquivo grande demais
para caber inteiro em memória, use `Client.ByteStream().Write`, que faz
streaming a partir de um `io.Reader` contra a superfície REAPI v2, ou leia
o arquivo em seus próprios chunks e monte o upload você mesmo.

## Idempotência

O CAS nativo é endereçado por conteúdo: duas chamadas `Put` com bytes
idênticos resolvem para o mesmo digest, então um upload duplicado não é
cobrado como armazenamento separado.

## Encanamento de contexto

O parâmetro `context.Context` de `Put` é propagado até a requisição HTTP
subjacente (`Client.do` constrói a requisição com
`http.NewRequestWithContext(ctx, ...)`), então um contexto cancelado ou
com timeout aborta um `Put` em andamento.

## Erros

Os métodos de `Client` retornam erros tipados que você pode capturar com
`errors.As`, não strings de mensagem simples:

| Tipo de erro | Causa | Ação |
|---|---|---|
| `*corelink.AuthError` | O PAT foi rejeitado, está ausente, ou seu tenant diverge do tenant da requisição | Confirme o PAT/tenant com uma chamada `Stat` primeiro; se isso também falhar, veja [Troubleshooting](./07-troubleshooting.mdx) |
| `*corelink.QuotaError` | A cota de bytes ou requisições do tenant está esgotada | Verifique os limites do plano antes de tentar novamente |
| `*corelink.DigestMismatchError` | Os bytes enviados geraram um digest diferente do calculado pelo servidor | Recalcule localmente; não tente novamente os mesmos bytes às cegas |

```go
digest, err := cli.Put(ctx, data)
if err != nil {
    var authErr *corelink.AuthError
    var quotaErr *corelink.QuotaError
    switch {
    case errors.As(err, &authErr):
        log.Fatalf("auth error (%d): %s", authErr.StatusCode, authErr.Message)
    case errors.As(err, &quotaErr):
        log.Fatalf("quota exceeded (%d): %s", quotaErr.StatusCode, quotaErr.Message)
    default:
        log.Fatalf("put failed: %v", err)
    }
}
```
