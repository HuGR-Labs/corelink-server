# Autentique o SDK Go

## Quando usar este guia

Você importa `go.corelink.humangr.com/corelink-go` e precisa chamar
qualquer API que leia ou grave no cache. A autenticação por PAT é
obrigatória; o SDK recusa construir um cliente sem um PAT.

## Pré-requisitos

- Go 1.22+.
- `corelink-go` é um módulo Go puro — sem cgo, sem biblioteca nativa,
  nada para compilar antes. Baixe-o pelo proxy de módulos do próprio
  CoreLink:

  ```bash
  GOPROXY=https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct go get go.corelink.humangr.com/corelink-go@v0.1.0
  ```

  A variável `GOPROXY` é obrigatória, não uma conveniência:
  `go.corelink.humangr.com` não tem registro DNS, então um `go get`
  simples falha com "no such host". O módulo é servido pelo proxy
  próprio do CoreLink — a primeira entrada da lista. A segunda entrada,
  `https://proxy.golang.org`, é o que busca as dependências públicas
  comuns deste módulo; `direct` é o fallback caso os dois proxies falhem.
- Um tenant CoreLink; PAT gerado em `https://humangr.com/corelink/en/customer/keys`.

## Construa o cliente

```go
package main

import (
    "context"
    "log"
    "os"

    "go.corelink.humangr.com/corelink-go"
)

func main() {
    client, err := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        TenantID: "acme-corp",
    })
    if err != nil {
        log.Fatal(err)
    }
    defer client.Close()

    ctx := context.Background()
    digest, err := client.Put(ctx, []byte("hello"))
    if err != nil {
        log.Fatal(err)
    }
    data, err := client.Get(ctx, digest)
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("wrote+read %d bytes at %s", len(data), digest.Hash)
}
```

`corelink.NewClient` recebe uma struct `Config` mais opções funcionais
opcionais (`corelink.WithTenantID`, para fixar o tenant separadamente do
literal `Config`). `Config.Endpoint` e `Config.PAT` são obrigatórios;
`NewClient` retorna erro se algum dos dois estiver vazio.
`Config.TenantID` é opcional de modo geral — um PAT já carrega seu
próprio tenant — mas as rotas nativas de CAS (`Put`/`Get`/`Stat`)
precisam de um, então defina-o a menos que use apenas a superfície
REAPI v2.

## Proibido: PAT em struct literal em código commitado

```go
// DO NOT DO THIS
client, _ := corelink.NewClient(corelink.Config{
    Endpoint: "https://corelink-api.humangr.com",
    PAT:      "corelink_pat_01ARZ3NDEKTSV4RRFFQ69G5FAV.4pT7q1yZ9vX2wL8cR5nB3sD6fH0jK1mQ8aV2eS.7bY4tN9oL2x",
    TenantID: "acme-corp",
})
```

Viola CTRL-CRED-001. Leia `Config.PAT` apenas de
`os.Getenv("CORELINK_PAT")`.

## Verifique

Não existe método `Whoami` neste cliente. O próprio `NewClient` apenas
valida o formato da configuração e não faz I/O de rede; um PAT inválido
ou revogado só aparece na primeira chamada real a `Put`/`Get`/`Stat`,
como um `*corelink.AuthError` tipado:

```go
digest, err := client.Put(ctx, []byte("healthcheck"))
if err != nil {
    var authErr *corelink.AuthError
    if errors.As(err, &authErr) {
        log.Fatalf("auth failed (%d): %s", authErr.StatusCode, authErr.Message)
    }
    log.Fatalf("request failed: %v", err)
}
log.Println("authenticated; wrote", digest.Hash)
```
