# SBOM access

> **DRAFT — pending Legal + Finance + Segurança review.** The procurement path
> below describes the *intended* customer-facing process; it is not yet
> contractually offered.

## What we publish

- **Format:** CycloneDX 1.5+ JSON (canonical per ADR-0014). SPDX 2.3+ available
  on request.
- **Cadence:** SBOM generation is an internal build step. No customer-facing
  SBOM artifact is currently distributed.
- **Coverage:** Worker, Container, and CLI binaries — Rust crates and JS deps
  inclusive.

## How enterprise customers request the SBOM

1. Open a support ticket of type **"Procurement / Segurança Review"**.
2. Provide your account ID and the release version you need the SBOM for.
3. We respond with current availability and any applicable NDA or licensing
   terms; no download URL or delivery SLA is currently promised.
4. For CLI release assets, verify the matching `.sha256` checksum before use.
   SBOM delivery and an independent verification artifact are not currently
   part of the public release contract.

## Verification example

There is no public SBOM download or independent verification command today.
Use the CLI release asset's `.sha256` sidecar when verifying a binary.
