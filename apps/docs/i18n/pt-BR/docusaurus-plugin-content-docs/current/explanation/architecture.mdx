## Topics this page will cover

1. **Why content-addressable?** Hash-keyed storage gives us trivial
   dedup, free integrity verification, and tenant isolation by key
   namespace rather than by encryption boundary.
2. **How dedup works.** Chunking strategy (rolling hash + fixed-size
   fallback), chunk-level reference counting, and tenant-isolated GC.
3. **Multi-region read-path.** R2 region pinning, fail-open vs
   fail-closed semantics, and the consistency model.
4. **BYOK envelope model.** Per-tenant DEK wrapped by customer KEK in
   their KMS — CoreLink never sees plaintext keys.
