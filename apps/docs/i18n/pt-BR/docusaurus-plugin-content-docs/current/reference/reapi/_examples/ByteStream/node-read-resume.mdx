# Node / TypeScript — `ByteStream.Read` with resume

Resume an interrupted download from the last byte written to disk.

## Code

```ts
import { createWriteStream, statSync, existsSync } from "node:fs";
import { CoreLinkClient } from "@corelink/client";

const path = "/tmp/big.bin";
const digest = { hash: "bdd9ea4a8e6b...", sizeBytes: 41943040 };
const offset = existsSync(path) ? statSync(path).size : 0;

const client = new CoreLinkClient({
  endpoint: "https://corelink-api.humangr.com",
  pat: process.env.CORELINK_PAT!,
});

const reader = await client.bytestream.read({ digest, readOffset: offset });
const sink = createWriteStream(path, { flags: "a" });
for await (const chunk of reader) sink.write(chunk);
sink.end();
console.log(`resumed from ${offset} → done`);
```

## Expected output

```text
resumed from 16777216 → done
```

## Common errors

| Status | Error taxonomy | Cause |
| --- | --- | --- |
| `OUT_OF_RANGE` | `COR_CAS_READ_OFFSET_OOR` | `readOffset > sizeBytes`. |
| `NOT_FOUND` | `COR_CAS_BLOB_MISSING` | Blob evicted between attempts. |
