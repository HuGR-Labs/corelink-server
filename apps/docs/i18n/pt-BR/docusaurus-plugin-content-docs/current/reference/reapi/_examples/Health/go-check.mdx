# Go — `Health.Check`

## Code

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.dev/corelink-go"
)

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(ctx, corelink.Config{
        Endpoint: "https://acme-dev.corelink.dev",
        PAT:      os.Getenv("CORELINK_PAT"),
    })
    defer client.Close()

    status, err := client.Health.Check(ctx)
    if err != nil { panic(err) }
    fmt.Println("server status =", status)
}
```

## Expected output

```text
server status = SERVING
```

## Common errors

| Status | Error taxonomy | Cause |
| --- | --- | --- |
| `UNAVAILABLE` | `COR_NET_TRANSIENT` | Server restarting. Retry. |
| `NOT_SERVING` | `COR_HEALTH_NOT_SERVING` | Draining. Reconnect to another region. |
