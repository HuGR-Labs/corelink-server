# Python — `Health.Check`

Cheap synchronous probe for liveness / readiness gates.

## Code

```python
import asyncio, os
from corelink import CoreLinkClient

async def main() -> None:
    async with CoreLinkClient(
        endpoint="https://acme-dev.corelink.dev",
        pat=os.environ["CORELINK_PAT"],
    ) as client:
        status = await client.health.check()
        print(f"server status = {status.name}")
        assert status.name == "SERVING"

asyncio.run(main())
```

## Expected output

```text
server status = SERVING
```

## Common errors

| Status | Error taxonomy | Cause |
| --- | --- | --- |
| `UNAVAILABLE` | `COR_NET_TRANSIENT` | Server is restarting or in lameduck mode. |
| `NOT_SERVING` | `COR_HEALTH_NOT_SERVING` | Server reports itself not serving (drain). |
