# Go — pick a digest function

Não há um endpoint `Capabilities` para negociar uma função de digest (veja
[GetCapabilities](./go-get-capabilities.mdx)). Escolha uma explicitamente
em vez disso: `corelink.DigestBLAKE3` é o padrão do CAS e a única função
que a superfície nativa `/v1/cas` aceita; use `corelink.DigestSHA256`
apenas quando você souber que a instância REAPI com a qual está falando
espera isso.

## Código

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Digest:   corelink.DigestBLAKE3,
    })
    defer client.Close()

    // Switch at runtime if a particular call needs SHA-256 instead.
    client.SetDigestFunction(corelink.DigestSHA256)
    fmt.Println("using SHA-256 for this call")

    _ = ctx
}
```

## Saída esperada

```text
using SHA-256 for this call
```

## Erros comuns

| Tipo de erro | Causa |
| --- | --- |
| `*corelink.AuthError` | PAT expirado. |
