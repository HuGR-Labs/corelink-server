# Go — `BatchReadBlobs`

Lê muitos blobs pequenos com o client-verify ligado por padrão. O
servidor não tem uma rota REAPI de batch-read, então `BatchRead` emite um
GET por digest e verifica cada blob antes de retorná-lo — é um wrapper de
conveniência, não uma única ida-e-volta.

## Pré-requisitos

```bash
GOPROXY=https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct go get go.corelink.humangr.com/corelink-go@v0.1.0
```

- `CORELINK_PAT` exportado

## Código

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, err := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Instance: "default",
    })
    if err != nil {
        panic(err)
    }
    defer client.Close()

    digests := []corelink.Digest{
        {Hash: "bdd9ea4a8e6b...", SizeBytes: 5},
        {Hash: "71c8b65b8b7e...", SizeBytes: 4},
    }
    blobs, err := client.CAS().BatchRead(ctx, digests)
    if err != nil {
        panic(err)
    }
    for d, data := range blobs {
        fmt.Printf("OK %s (%d B)\n", d.Hash[:12], len(data))
    }
}
```

## Saída esperada

```text
OK bdd9ea4a8e6b (5 B)
OK 71c8b65b8b7e (4 B)
```

## Erros comuns

| Tipo de erro | Causa |
| --- | --- |
| `*corelink.NotFoundError` | Digest não presente (ou removido). |
| `*corelink.DigestMismatchError` | O client-verify rejeitou os bytes retornados. |
