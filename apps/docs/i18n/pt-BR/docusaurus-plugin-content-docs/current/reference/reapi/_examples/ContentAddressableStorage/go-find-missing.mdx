# Go — `FindMissingBlobs`

## Pré-requisitos

```bash
GOPROXY=https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct go get go.corelink.humangr.com/corelink-go@v0.1.0
```

- `CORELINK_PAT` exportado

## Código

```go
package main

import (
    "context"
    "crypto/sha256"
    "encoding/hex"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func digest(b []byte) corelink.Digest {
    s := sha256.Sum256(b)
    return corelink.Digest{Hash: hex.EncodeToString(s[:]), SizeBytes: int64(len(b))}
}

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Instance: "default",
    })
    defer client.Close()

    blobs := [][]byte{[]byte("alpha"), []byte("beta"), []byte("gamma")}
    digests := make([]corelink.Digest, len(blobs))
    for i, b := range blobs {
        digests[i] = digest(b)
    }
    missing, err := client.CAS().FindMissing(ctx, digests)
    if err != nil {
        panic(err)
    }
    fmt.Printf("%d/%d missing\n", len(missing), len(digests))
}
```

## Saída esperada

```text
2/3 missing
```

## Erros comuns

| Tipo de erro | Causa |
| --- | --- |
| `*corelink.AuthError` | PAT expirado. |
| `*corelink.RateLimitError` | Requisições demais; aguarde `RetryAfter`. |
