# Go — `ByteStream.Read`

## Código

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Instance: "default",
    })
    defer client.Close()

    digest := corelink.Digest{Hash: "bdd9ea4a8e6b...", SizeBytes: 41943040}
    out, err := os.Create("/tmp/big.bin")
    if err != nil { panic(err) }
    defer out.Close()

    n, err := client.ByteStream().Read(ctx, digest, out)
    if err != nil { panic(err) }
    fmt.Printf("downloaded %d B\n", n)
}
```

## Saída esperada

```text
downloaded 41943040 B
```

## Erros comuns

| Tipo de erro | Causa |
| --- | --- |
| `*corelink.NotFoundError` | Digest removido ou nunca escrito. |
| `*corelink.DigestMismatchError` | O client-verify rejeitou os bytes transferidos. |
