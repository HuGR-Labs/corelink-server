# Go — `ByteStream.Write`

## Código

```go
package main

import (
    "context"
    "crypto/sha256"
    "encoding/hex"
    "fmt"
    "io"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Instance: "default",
        Digest:   corelink.DigestSHA256,
    })
    defer client.Close()

    f, _ := os.Open("/tmp/big.bin")
    defer f.Close()
    h := sha256.New()
    if _, err := io.Copy(h, f); err != nil { panic(err) }
    digest := corelink.Digest{Hash: hex.EncodeToString(h.Sum(nil)), SizeBytes: fileSize(f)}
    f.Seek(0, 0)

    if err := client.ByteStream().Write(ctx, digest, f); err != nil { panic(err) }
    fmt.Printf("uploaded %d B sha256:%s...\n", digest.SizeBytes, digest.Hash[:12])
}

func fileSize(f *os.File) int64 {
    st, _ := f.Stat(); return st.Size()
}
```

## Saída esperada

```text
uploaded 41943040 B sha256:bdd9ea4a8e6b...
```

## Erros comuns

| Tipo de erro | Causa |
| --- | --- |
| `*corelink.DigestMismatchError` | O servidor calculou um digest diferente do enviado para os bytes recebidos — reportado a partir de uma resposta 422. |
| `*corelink.AuthError` | PAT rejeitado no meio do upload. |
