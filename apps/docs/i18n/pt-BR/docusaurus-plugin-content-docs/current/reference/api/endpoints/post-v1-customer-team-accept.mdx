# `POST` `/v1/customer/team/accept`

> Redeem a team invitation for the verified Clerk user.

Requires a Clerk session whose primary email is explicitly verified. Submit
`invitation_token`; tenant scope comes only from its stored digest. Expiry,
audit and the one-row transition are atomic, so replay fails closed.

| Status | Meaning |
| --- | --- |
| `200` | Invitation accepted exactly once. |
| `400`/`401`/`403` | Invalid request, credentials or authorization. |
| `500` | Server error. |
