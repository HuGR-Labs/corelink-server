# `POST` `/v1/privacy/dsr/{action}`

> Submit a Data Subject Request (GDPR / LGPD / CCPA).

- **Operation ID:** `dsrSubmit`
- **Tag:** `privacy-dsr`
- **Rate-limit class:** privacy-strict (10 req/hour/subject)

## Description

6 supported actions per `corelink-dsr::event::DsrRequestKind`:
`access`, `portability`, `rectification`, `erasure`, `restriction`,
`objection`. Destructive arms (`erasure`, `rectification`) require
a fresh MFA step-up token via `X-MFA-Step-Up-Token`.

Returns an RS256-signed JWT receipt (90-day validity) on
acceptance. SLA deadline is jurisdiction-bound (GDPR 30d / LGPD
15d / CCPA 45d).

## Authentication

- `BearerPAT`
- `ClerkSessionCookie`
