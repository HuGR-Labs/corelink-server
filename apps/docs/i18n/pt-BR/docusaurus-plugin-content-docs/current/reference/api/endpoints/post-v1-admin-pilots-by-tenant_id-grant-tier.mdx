# `POST` `/v1/admin/pilots/{tenant_id}/grant-tier`

> Grant pilot tier and cap.

- **Operation ID:** `adminPilotsGrantTier`
- **Tag:** `admin-pilot`
- **Rate-limit class:** default (600 req/min/PAT)

## Description

Replaces the wave-27 `grant-pilot-tier.sh` shell script.
Transitions `pilot_state` NEW → ACTIVE atomically with
`tier_granted_at_ms` set.
