# `POST` `/v1/admin/ops`

> Submit a dual-approval-gated admin operation.

- **Operation ID:** `adminOpsSubmit`
- **Tag:** `admin`
- **Rate-limit class:** admin-strict (60 req/min/PAT, dual-approval gate)

## Description

Implemented by `corelink-admin-api::middleware::AdminApiPipeline`.
Enforces `INV-ADMIN-DUAL-APPROVAL` (caller + distinct approver
with fresh MFA) and audit-emit-BEFORE-handler atomically.
Op taxonomy: `ConfigRollback`, `SecretRotationStart`,
`TenantTombstone`, plus runbook-specific variants.

## Authentication

- `BearerPAT` (scopes: `admin`)

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `X-Admin-Operation-Reason` | `header` | yes | `string` | Free-text justification recorded in the audit envelope for every admin mutation. Required for all `/v1/admin/*` write endpoints. |

## Request body

- **Media type:** `application/json`
- **Required:** yes
- **Schema:** [`AdminOpRequest`](#schema-adminoprequest)

## Responses

| Status | Schema | Description |
| --- | --- | --- |
| `202` | [`AdminOpAccepted`](#schema-adminopaccepted) | Op accepted; result available at `GET /v1/admin/ops/\{op_id\}`. |
| `401` | [`ErrorEnvelope`](#schema-errorenvelope) | Missing or invalid credentials. |
