# Verificar a taxa de acerto do cache

O tutorial só está completo quando você consegue provar que o cache está
funcionando. Esta página reúne três verificações independentes.

## A. Logs de Bazel BES / Buck2

Bazel:

```bash
bazel build //:hello 2>&1 | grep -E "remote cache hit|disk cache hit|processes:"
# INFO: 12 processes: 11 remote cache hit, 1 internal.
```

Buck2:

```bash
buck2 build //:hello --show-output 2>&1 | grep -iE "cache hits"
```

Uma build 100% verde que imprime **0 processes** é o sinal isolado mais forte — o
Bazel/Buck2 curto-circuitou cada ação através do cache.

## B. Microbenchmark de CLI

Execute o `corelink bench` embutido (grava um blob determinístico de 16 KiB 50× e
depois o lê 50×):

```bash
corelink bench --put 50 --get 50
# put p50=8.2ms  p95=13.1ms  err=0/50
# get p50=2.1ms  p95= 4.8ms  err=0/50 hit_ratio=100%
```

`hit_ratio=100%` na passagem de leitura confirma que as requisições da segunda em
diante são atendidas pelo cache.

## C. Painel da UI de administração

1. Abra `https://humangr.com/corelink/orgs/<your-org>/observability`.
2. Selecione **Cache hit ratio (5m, by tenant)**.
3. Dispare uma nova build (`bazel clean && bazel build //...`).
4. A série deve saltar para ~100% após a primeira passagem quente.

O painel Grafana de taxa de acerto está documentado em
`dashboards/cache_hit_ratio.json`; os limiares de alerta ficam em
`infra/alerts/cache_hit_ratio.yaml`.

## Solução de problemas

| Sintoma | Causa provável | Correção |
| --- | --- | --- |
| `hit_ratio=0%` na segunda build | o cache de disco local atendeu a requisição, nunca tocou o remoto | `bazel clean` e defina `build --noremote_accept_cached=false` para forçar a leitura remota |
| Erros `UNAUTHENTICATED` | PAT expirado ou ambiente errado | Execute novamente `corelink doctor --check-auth`, regenere o PAT |
| `COR_CAS_DIGEST_MISMATCH` | bytes corrompidos em trânsito | `client_verify` rejeitou o blob — abra uma issue, não desative a verificação |
| Lento `p95 > 50ms` | distante da edge mais próxima | Fixe a região mais próxima no `.bazelrc`: `build --remote_cache=https://<region>.<tenant>.corelink.humangr.com/v1/cache` |
