# Upload a blob

## When to use this guide

Use this when you need to persist arbitrary bytes (a build output, a model
weight, a packaged tarball) into the CoreLink CAS, and you want the SDK to
compute the BLAKE3 digest for you.

If you already have a digest and want to skip recomputation, supply it via
`expected_digest=`.

## Prerequisites

- Authentication configured (see [01-authenticate](./01-authenticate)).

## Minimal example

```python
import asyncio
from pathlib import Path
from corelink import AsyncCoreLinkClient

async def main() -> None:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        data = Path("./build/output.tar").read_bytes()
        digest = await client.put(data)
        print(f"stored: {digest}")  # 64-char BLAKE3 hex
```

> The synchronous twin is `corelink.CoreLinkClient` — same methods without
> `async`/`await` (`digest = client.put(data)`), used with a plain `with` block.

## Streaming upload (large blobs)

For large files use the streaming overload to avoid loading the file fully into
memory — the BLAKE3 digest is computed in one rewound pass over the open file
handle, then the same handle is streamed to the server:

```python
async def upload_large(path: str) -> str:
    async with AsyncCoreLinkClient(tenant_id="acme-corp") as client:
        with open(path, "rb") as f:
            return await client.put_stream(f, chunk_size=4 * 1024 * 1024)
```

## Idempotency

`put` is idempotent on the digest. A second upload of identical bytes returns
the same digest with no extra storage cost (CTRL-CAS-001 dedupe).

## Errors

| Exception | Cause | Action |
|---|---|---|
| `CoreLinkAuthError` | PAT missing or revoked (HTTP 401) | Re-run [01-authenticate](./01-authenticate) |
| `CoreLinkQuotaError` | Tenant over quota (HTTP 402) | Inspect `corelink stat`; see [troubleshooting](./07-troubleshooting) |
| `CoreLinkDigestMismatchError` | `expected_digest` did not match `blake3(body)` (HTTP 422) | Recompute locally; do not retry blindly |

All import from `corelink.exceptions` (or the top-level `corelink` package) and
subclass `CoreLinkError`.
