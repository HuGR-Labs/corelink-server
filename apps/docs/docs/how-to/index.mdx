# How-to guides

**Task-oriented.** How-to guides assume competence and answer "how do I
do X?". They are recipes, not lessons — they skip context and focus on
the steps.

- **Integrate CoreLink with Buck2 remote cache** — `.buckconfig`
  + auth.
- **Request a DSR export and verify it** — for LGPD / GDPR data subject
