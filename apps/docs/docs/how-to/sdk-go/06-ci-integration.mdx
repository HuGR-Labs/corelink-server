# CI integration

## When to use this guide

Your build is a Go project (or its smoke tests are written in Go) and you
want CoreLink as a shared cache without shelling out to the CLI.

## GitHub Actions

```yaml
# .github/workflows/build.yml
jobs:
  build:
    runs-on: ubuntu-latest
    env:
      CORELINK_PAT: ${{ secrets.CORELINK_PAT }}
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v5
        with:
          go-version: "1.22"
      - run: go run ./ci/warm-cache
```

```go
// ci/warm-cache/main.go
package main

import (
    "context"
    "log"
    "os"

    "github.com/HumanGuardrail/corelink-go/corelink"
)

func main() {
    ctx := context.Background()
    cli, err := corelink.NewClient(ctx,
        corelink.WithTenantID(os.Getenv("CORELINK_TENANT")),
    )
    if err != nil {
        log.Fatal(err)
    }
    defer cli.Close()

    report, err := cli.Bench(ctx, corelink.BenchOptions{Read: true, Samples: 10})
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("p50=%vms p99=%vms", report.P50Ms, report.P99Ms)
    if report.P99Ms > 500 {
        os.Exit(1)
    }
}
```

## GitLab CI

```yaml
build:
  image: golang:1.22
  variables:
    CORELINK_PAT: $CORELINK_PAT  # masked
  script:
    - go run ./ci/warm-cache
```

## CircleCI

```yaml
version: 2.1
jobs:
  build:
    docker:
      - image: cimg/go:1.22
    environment:
      CORELINK_PAT: $CORELINK_PAT
    steps:
      - checkout
      - run: go run ./ci/warm-cache
```

## Job-scoped PATs

Mint a short-lived PAT per pipeline via the admin API and inject into the
runner env. See [CLI reference](../../reference/cli/index.mdx).
