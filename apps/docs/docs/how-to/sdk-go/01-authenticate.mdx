# Authenticate the Go SDK

## When to use this guide

You import `go.corelink.humangr.com/corelink-go` and need to call any
cache-mutating or cache-reading API. PAT auth is mandatory; the SDK refuses
to construct a client without one.

## Prerequisites

- Go 1.22+.
- `corelink-go` is a pure Go module — no cgo, no native library, nothing to
  build first. Fetch it through CoreLink's own module proxy:

  ```bash
  GOPROXY=https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct go get go.corelink.humangr.com/corelink-go@v0.1.0
  ```

  The `GOPROXY` setting is mandatory, not a nicety: `go.corelink.humangr.com`
  has no DNS record, so a plain `go get` fails with "no such host." The
  module is served from CoreLink's own proxy — the first entry in the list.
  The second entry, `https://proxy.golang.org`, is what fetches this
  module's ordinary public dependencies; `direct` is the fallback if both
  proxies miss.
- A CoreLink tenant; PAT minted at `https://humangr.com/corelink/en/customer/keys`.

## Construct the client

```go
package main

import (
    "context"
    "log"
    "os"

    "go.corelink.humangr.com/corelink-go"
)

func main() {
    client, err := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        TenantID: "acme-corp",
    })
    if err != nil {
        log.Fatal(err)
    }
    defer client.Close()

    ctx := context.Background()
    digest, err := client.Put(ctx, []byte("hello"))
    if err != nil {
        log.Fatal(err)
    }
    data, err := client.Get(ctx, digest)
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("wrote+read %d bytes at %s", len(data), digest.Hash)
}
```

`corelink.NewClient` takes a `Config` struct plus optional functional
options (`corelink.WithTenantID`, for pinning the tenant separately from the
Config literal). `Config.Endpoint` and `Config.PAT` are required; `NewClient`
returns an error if either is empty. `Config.TenantID` is optional in
general — a PAT already carries its own tenant — but the native CAS routes
(`Put`/`Get`/`Stat`) need one, so set it unless you only use the REAPI v2
surface.

## Forbidden: PAT in struct literal in committed code

```go
// DO NOT DO THIS
client, _ := corelink.NewClient(corelink.Config{
    Endpoint: "https://corelink-api.humangr.com",
    PAT:      "corelink_pat_0123456789ABCDEF.AAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAAA.BBBBBBBBBBBBBBBBBBBBBA",
    TenantID: "acme-corp",
})
```

Violates CTRL-CRED-001. Read `Config.PAT` from `os.Getenv("CORELINK_PAT")`
only.

## Verify

There is no `Whoami` method on this client. `NewClient` itself only
validates the config shape and performs no network I/O; an invalid or
revoked PAT surfaces the first time you actually call `Put`/`Get`/`Stat`, as
a typed `*corelink.AuthError`:

```go
digest, err := client.Put(ctx, []byte("healthcheck"))
if err != nil {
    var authErr *corelink.AuthError
    if errors.As(err, &authErr) {
        log.Fatalf("auth failed (%d): %s", authErr.StatusCode, authErr.Message)
    }
    log.Fatalf("request failed: %v", err)
}
log.Println("authenticated; wrote", digest.Hash)
```
