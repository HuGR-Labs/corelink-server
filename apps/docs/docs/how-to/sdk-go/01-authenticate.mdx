# Authenticate the Go SDK

## When to use this guide

You import `github.com/HumanGuardrail/corelink-go/v1` and need to call any
cache-mutating or cache-reading API. PAT auth is mandatory; the SDK refuses
to construct a client without one.

## Prerequisites

- Go 1.21+.
- The module has **no external Go dependencies** — it links against
  `libcorelink_go` via cgo. Build the Rust crate first, then the Go module:

  ```bash
  cargo build --release -p corelink-go
  CGO_LDFLAGS="-L../target/release -lcorelink_go" go build ./...
  ```

  `go get github.com/HumanGuardrail/corelink-go/v1` alone is not enough —
  without the compiled `libcorelink_go` on the link path, the build fails at
  the cgo step.
- A CoreLink tenant; PAT minted at `https://humangr.com/corelink/en/customer/keys`.

## Construct the client

```go
package main

import (
    "context"
    "log"
    "os"

    "github.com/HumanGuardrail/corelink-go/v1"
)

func main() {
    client, err := corelink.NewClient(corelink.Config{
        PAT:      os.Getenv("CORELINK_PAT"),
        TenantID: "acme-corp",
    })
    if err != nil {
        log.Fatal(err)
    }
    defer client.Close()

    ctx := context.Background()
    digest, err := client.Put(ctx, []byte("hello"))
    if err != nil {
        log.Fatal(err)
    }
    data, err := client.Get(ctx, digest)
    if err != nil {
        log.Fatal(err)
    }
    log.Printf("wrote+read %d bytes at %s", len(data), digest)
}
```

`corelink.NewClient` takes a single `Config` struct — there is no
`WithTenantID` / `WithPAT` functional-options API. `Config.PAT` and
`Config.TenantID` are both required; `NewClient` returns an error if either
is empty.

## Forbidden: PAT in struct literal in committed code

```go
// DO NOT DO THIS
client, _ := corelink.NewClient(corelink.Config{
    PAT:      "corelink_pat_01ARZ3NDEKTSV4RRFFQ69G5FAV.4pT7q1yZ9vX2wL8cR5nB3sD6fH0jK1mQ8aV2eS.7bY4tN9oL2x",
    TenantID: "acme-corp",
})
```

Violates CTRL-CRED-001. Read `Config.PAT` from `os.Getenv("CORELINK_PAT")`
only.

## Verify

There is no `Whoami` method on this client and no dedicated `AuthError`
type — errors are plain `error` values. `NewClient` itself only validates
that `PAT`/`TenantID` are non-empty; an invalid or revoked PAT surfaces the
first time you actually call `Put`/`Get`/`Stat`:

```go
digest, err := client.Put(ctx, []byte("healthcheck"))
if err != nil {
    log.Fatalf("auth or network failure: %v", err)
}
log.Println("authenticated; wrote", digest)
```
