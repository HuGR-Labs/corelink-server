# Action Cache

## When to use this guide

You expected an Action Cache client in the Go SDK and want to know what to do
instead. Read this before wiring anything: the capability is real on the server
but absent from this SDK, so the honest options are the HTTP recipe below or the
JS/TS client.

## The Go SDK does not implement an Action Cache client

`corelink-go` (`corelink.Client`, `corelink-go/corelink.go`) exposes exactly
three data-plane methods — `Put`, `Get`, `Stat` — plus `Close` and
`IsClientVerifyEnabled`. There is no `ActionCache()` method, no
`corelink.ActionResult` type, and no `corelink.ErrActionCacheMiss` in this
SDK today.

If you need Action Cache from JS/TS, use `@corelink/client`, which does
implement it (`client.actionCache.get` / `.put`) — see the
[JS/TS Action Cache guide](../sdk-js/04-action-cache.mdx).

## Working around it from Go today

The Action Cache is a real server surface (`routes/ac.rs`, REAPI v2) even
though this SDK doesn't wrap it — call it directly over HTTP with the same
PAT you already configured for the `Client`:

```go
func getOrRun(ctx context.Context, pat, tenantID, baseURL, actionDigest string) ([]byte, error) {
    req, err := http.NewRequestWithContext(ctx, http.MethodGet,
        fmt.Sprintf("%s/v1/ac/%s/%s", baseURL, tenantID, actionDigest), nil)
    if err != nil {
        return nil, err
    }
    req.Header.Set("Authorization", "Bearer "+pat)

    resp, err := http.DefaultClient.Do(req)
    if err != nil {
        return nil, err
    }
    defer resp.Body.Close()

    if resp.StatusCode == http.StatusNotFound {
        return runLocallyAndStore(ctx, actionDigest)
    }
    if resp.StatusCode != http.StatusOK {
        return nil, fmt.Errorf("ac lookup: unexpected status %d", resp.StatusCode)
    }
    return io.ReadAll(resp.Body) // opaque ActionResult bytes — you own the encoding
}
```

The Action Cache stores an opaque byte payload keyed by a 64-hex action
digest — the server does not parse it, so how you encode/decode the
`ActionResult` is up to you, same as the JS SDK.
