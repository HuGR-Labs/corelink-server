# Upload a blob

## When to use this guide

You have a `[]byte` and want it persisted into the CoreLink CAS. `Put`
computes the BLAKE3 digest for you — there is no way to supply a
pre-computed digest client-side in this SDK (unlike `corelink-py`'s
`expected_digest=`).

## Prerequisites

- Authentication configured ([01-authenticate](./01-authenticate.mdx)).

## Minimal example

```go
import (
    "context"
    "os"

    "go.corelink.humangr.com/corelink-go"
)

func upload(ctx context.Context, cli *corelink.Client, path string) (string, error) {
    data, err := os.ReadFile(path)
    if err != nil {
        return "", err
    }
    digest, err := cli.Put(ctx, data)
    if err != nil {
        return "", err
    }
    return digest.Hash, nil
}
```

## No streaming upload on the native CAS surface

`Client` has exactly three native CAS methods — `Put`, `Get`, `Stat` — and
`Put` takes a `[]byte`, not an `io.Reader`; there is no `PutStream` or
chunk-size option on this surface. For a file too large to hold fully in
memory, use `Client.ByteStream().Write`, which streams from an `io.Reader`
against the REAPI v2 surface instead, or read the file in your own chunks
and assemble the upload yourself.

## Idempotency

The native CAS is content-addressed: two `Put` calls with identical bytes
resolve to the same digest, so a duplicate upload is not billed as separate
storage.

## Context plumbing

`Put`'s `context.Context` parameter is wired through to the underlying HTTP
request (`Client.do` builds the request with
`http.NewRequestWithContext(ctx, ...)`), so a cancelled or timed-out context
aborts an in-flight `Put`.

## Errors

`Client` methods return typed errors you can match with `errors.As`, not
plain message strings:

| Error type | Cause | Action |
|---|---|---|
| `*corelink.AuthError` | The PAT was rejected, missing, or its tenant disagreed with the request's tenant | Confirm the PAT/tenant with a `Stat` call first; if that also fails, see [Troubleshooting](./07-troubleshooting.mdx) |
| `*corelink.QuotaError` | The tenant's byte or request quota is exhausted | Check plan limits before retrying |
| `*corelink.DigestMismatchError` | The uploaded bytes hashed to a different digest than the server computed | Recompute locally; do not retry the same bytes blindly |

```go
digest, err := cli.Put(ctx, data)
if err != nil {
    var authErr *corelink.AuthError
    var quotaErr *corelink.QuotaError
    switch {
    case errors.As(err, &authErr):
        log.Fatalf("auth error (%d): %s", authErr.StatusCode, authErr.Message)
    case errors.As(err, &quotaErr):
        log.Fatalf("quota exceeded (%d): %s", quotaErr.StatusCode, quotaErr.Message)
    default:
        log.Fatalf("put failed: %v", err)
    }
}
```
