# Troubleshooting

## When to use this guide

A `@corelink/client` call is throwing or hanging. Every error extends
`CoreLinkError` and carries a `status` (HTTP status, when server-originated)
and a short `code` (the server's reason string). Inspect them:

## Diagnostic flow

```typescript
import { CoreLinkError } from "@corelink/client";

try {
  await client.get(digest);
} catch (e) {
  if (e instanceof CoreLinkError) {
    console.error(`${e.name} status=${e.status} code=${e.code}: ${e.message}`);
  }
  throw e;
}
```

## Common errors

Map the thrown class to its cause and fix:

| Class | Status | First action |
|---|---|---|
| `AuthError` | 401 | Re-export `CORELINK_PAT`; if revoked, mint a new PAT. |
| `ForbiddenError` | 403 | Wrong tenant, or the PAT lacks the required cache scope. |
| `QuotaError` | 402 | Tenant over its storage cap / spend ceiling. |
| `NotFoundError` / `ActionCacheMiss` | 404 | Digest / action not stored for this tenant. |
| `GoneError` | 410 | Artifact was erased (GDPR/DSR); it will not return. |
| `DigestMismatchError` | 422 / verify | Discard the bytes; re-fetch or re-upload. |
| `RateLimitError` | 429 | Auto-retried; if it still surfaces, lower concurrency. |
| `ServerError` | 5xx | Transient backend fault; retry with backoff. |
| `ConnectError` | — | Transport failure; check network / `baseUrl`. |

## No native or WASM build step

`@corelink/client` is pure JavaScript (BLAKE3 via `@noble/hashes`). There is no
`.wasm` artifact to bundle and no bundler asset rule to configure — if you hit a
resolution error, it is an ordinary ESM package resolution issue, not a WASM one.

## Lifecycle

`close()` is a no-op today (the SDK uses the platform `fetch` and holds no
persistent pool), but call it anyway so your code stays correct if a future
release adds pooling:

```typescript
const client = new CoreLinkClient({ tenantId: "acme-corp" });
try {
  await client.get(digest);
} finally {
  await client.close();
}
```

## Verbose logging

```bash
export CORELINK_LOG=debug
```

Structured JSON logs go to `stderr`. Pipe through `jq`:

```bash
node ./script.mjs 2>&1 | jq 'select(.level=="error")'
```

## Filing a bug

Include `corelink doctor --json` output. Never include your PAT.
