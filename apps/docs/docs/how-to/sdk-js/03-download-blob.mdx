# Download a blob

## When to use this guide

You hold a BLAKE3 digest and need the bytes. The SDK verifies the digest
client-side via WASM by default (CTRL-CAS-002).

## Prerequisites

- A known BLAKE3 digest.
- Authentication configured.

## Minimal example

```typescript
const data: Uint8Array = await client.get(digest);
// Already BLAKE3-verified; if verify failed, get() threw.
```

## Streaming download

```typescript
import { writeFile } from "node:fs/promises";

async function streamToFile(digest: string, dest: string): Promise<void> {
  const stream = await client.getStream(digest);
  const chunks: Uint8Array[] = [];
  for await (const chunk of stream) chunks.push(chunk);
  // stream completion validates the BLAKE3 root; an iteration error means
  // the bytes are corrupt and must not be persisted.
  await writeFile(dest, Buffer.concat(chunks));
}
```

In a browser, pipe directly to a `FileSystemWritableFileStream` or to a
`Blob` constructor.

## Opting out of verification

**Strongly discouraged**. The opt-out exists only for transport benchmarks.
The SDK emits `console.warn("corelink.client.verify_disabled")` per
CTRL-CAS-002.

```typescript
const data = await client.get(digest, { verify: false });
```

## Errors

| Class | Meaning |
|---|---|
| `NotFoundError` | Digest not in tenant CAS |
| `DigestMismatchError` | Bytes corrupted; do not use |
| `RegionError` | Blob in another region; check `corelink stat` |
