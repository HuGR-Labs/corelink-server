# Download a blob

## When to use this guide

You hold a BLAKE3 digest and need the bytes. The SDK verifies the digest
client-side (pure-JS `@noble/hashes`) by default (CTRL-CAS-002).

## Prerequisites

- A known BLAKE3 digest.
- Authentication configured.

## Minimal example

```typescript
const data: Uint8Array = await client.get(digest);
// Already BLAKE3-verified; if verify failed, get() threw.
```

## Download to a file

`get` returns the whole verified `Uint8Array`; write it out:

```typescript
import { writeFile } from "node:fs/promises";

async function getToFile(digest: string, dest: string): Promise<void> {
  const data = await client.get(digest); // throws DigestMismatchError if corrupt
  await writeFile(dest, data);
}
```

A chunked/streaming download API is not part of this release.

## Opting out of verification

**Strongly discouraged**. The opt-out exists only for transport benchmarks.
Disable globally at construction (`clientVerify: false` — logs
`corelink.client.verify_disabled` per CTRL-CAS-002), or per call:

```typescript
const data = await client.get(digest, { verify: false });
```

## Errors

| Class | Meaning |
|---|---|
| `NotFoundError` | Digest not in tenant CAS (404) |
| `GoneError` | Artifact erased (410); do not resurrect |
| `DigestMismatchError` | Bytes corrupted; do not use |
