# Go — `BatchReadBlobs`

Read many small blobs with client-verify default on. The server has no
batch-read REAPI route, so `BatchRead` issues one GET per digest and
verifies each blob before returning it — it is a convenience wrapper, not a
single round-trip.

## Prerequisites

```bash
GOPROXY=https://humangr.com/corelink/docs/goproxy,https://proxy.golang.org,direct go get go.corelink.humangr.com/corelink-go@v0.1.0
```

- `CORELINK_PAT` exported

## Code

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, err := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Instance: "default",
    })
    if err != nil {
        panic(err)
    }
    defer client.Close()

    digests := []corelink.Digest{
        {Hash: "bdd9ea4a8e6b...", SizeBytes: 5},
        {Hash: "71c8b65b8b7e...", SizeBytes: 4},
    }
    blobs, err := client.CAS().BatchRead(ctx, digests)
    if err != nil {
        panic(err)
    }
    for d, data := range blobs {
        fmt.Printf("OK %s (%d B)\n", d.Hash[:12], len(data))
    }
}
```

## Expected output

```text
OK bdd9ea4a8e6b (5 B)
OK 71c8b65b8b7e (4 B)
```

## Common errors

| Error type | Cause |
| --- | --- |
| `*corelink.NotFoundError` | Digest not present (or evicted). |
| `*corelink.DigestMismatchError` | Client-verify rejected returned bytes. |
