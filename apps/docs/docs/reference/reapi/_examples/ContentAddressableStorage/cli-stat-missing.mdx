# CLI — `corelink stat`

Verify a blob is present without downloading it. Useful for CI prefetch checks.

## Prerequisites

- `corelink` CLI installed
- `CORELINK_PAT` exported

## Code

```bash
# CoreLink's CAS is addressed by BLAKE3 (a `blake3:`/`sha256:` prefix is
# accepted and stripped, but the digest itself must be BLAKE3 — a SHA-256
# digest of the same bytes will simply never match).
corelink stat bdd9ea4a8e6b1c2d3e4f5061728394a5b6c7d8e9f001122334455667788990a
```

## Expected output

```text
Digest:  bdd9ea4a8e6b1c2d3e4f5061728394a5b6c7d8e9f001122334455667788990a
Exists:  true
Size:    16 bytes
Tenant:  acme-prod
```

Pass the global `--output json` flag for a machine-readable form:

```bash
corelink --output json stat bdd9ea4a8e6b1c2d3e4f5061728394a5b6c7d8e9f001122334455667788990a
```

```json
{"digest": "bdd9ea4a8e6b1c2d3e4f5061728394a5b6c7d8e9f001122334455667788990a", "exists": true, "size_bytes": 16, "tenant_id": "acme-prod"}
```

`stat` issues a `HEAD` against `/v1/cas/<tenant>/<digest>` — there is no bulk/batch variant today; script over a list of digests by looping the command.

## Common errors

| Condition | Cause | Fix |
| --- | --- | --- |
| `exists: false` | Blob not found | Upload via [`corelink put`](./cli-put-get) |
| Non-zero exit, `401`/auth error | Invalid or missing PAT | Re-mint PAT (`corelink login`) |
| Non-zero exit, malformed digest | Digest is not 64 hex chars | Use the bare BLAKE3 hex digest (an optional `blake3:`/`sha256:` prefix is stripped, but the value itself must be BLAKE3) |
