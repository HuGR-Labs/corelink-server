# Go — Kubernetes readiness gate

Wire `Health.Check` into a Kubernetes readiness probe handler.

## Code

```go
package main

import (
    "context"
    "net/http"
    "os"
    "time"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    client, _ := corelink.NewClient(context.Background(), corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
    })
    http.HandleFunc("/ready", func(w http.ResponseWriter, r *http.Request) {
        ctx, cancel := context.WithTimeout(r.Context(), 2*time.Second)
        defer cancel()
        s, err := client.Health.Check(ctx)
        if err != nil || s.String() != "SERVING" {
            http.Error(w, "not ready", http.StatusServiceUnavailable)
            return
        }
        w.WriteHeader(http.StatusOK)
    })
    http.ListenAndServe(":8080", nil)
}
```

## Expected output

```text
$ curl -i http://localhost:8080/ready
HTTP/1.1 200 OK
```

## Common errors

| HTTP status | Cause | Fix |
| --- | --- | --- |
| `503` | Upstream `Health.Check` failed | Trigger pod restart via liveness probe |
