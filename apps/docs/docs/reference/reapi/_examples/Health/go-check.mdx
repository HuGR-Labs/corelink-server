# Go — `Health.Check`

## Code

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
    })
    defer client.Close()

    status, err := client.Health(ctx)
    if err != nil { panic(err) }
    fmt.Println("server ok =", status.OK)
}
```

## Expected output

```text
server ok = true
```

## Common errors

| Error type | Cause |
| --- | --- |
| plain error (network) | Server unreachable or restarting. Retry. |
| `*corelink.AuthError` | PAT rejected. |
