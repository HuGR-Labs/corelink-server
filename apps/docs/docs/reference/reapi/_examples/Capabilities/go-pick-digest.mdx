# Go — pick a digest function

There is no `Capabilities` endpoint to negotiate a digest function against
(see [GetCapabilities](./go-get-capabilities.mdx)). Pick one explicitly
instead: `corelink.DigestBLAKE3` is the CAS default and the only function
the native `/v1/cas` surface accepts; use `corelink.DigestSHA256` only when
you know the REAPI instance you're talking to expects it.

## Code

```go
package main

import (
    "context"
    "fmt"
    "os"

    corelink "go.corelink.humangr.com/corelink-go"
)

func main() {
    ctx := context.Background()
    client, _ := corelink.NewClient(corelink.Config{
        Endpoint: "https://corelink-api.humangr.com",
        PAT:      os.Getenv("CORELINK_PAT"),
        Digest:   corelink.DigestBLAKE3,
    })
    defer client.Close()

    // Switch at runtime if a particular call needs SHA-256 instead.
    client.SetDigestFunction(corelink.DigestSHA256)
    fmt.Println("using SHA-256 for this call")

    _ = ctx
}
```

## Expected output

```text
using SHA-256 for this call
```
