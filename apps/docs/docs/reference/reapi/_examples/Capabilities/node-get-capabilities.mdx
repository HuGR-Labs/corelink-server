# Node / TypeScript — `Capabilities.GetCapabilities`

## Code

```ts
import { CoreLinkClient } from "@corelink/client";

const client = new CoreLinkClient({
  endpoint: "https://acme-dev.corelink.dev",
  pat: process.env.CORELINK_PAT!,
});

const caps = await client.capabilities.get();
console.log("max_batch_total_size_bytes =", caps.cacheCapabilities.maxBatchTotalSizeBytes);
console.log("digest functions =", caps.cacheCapabilities.digestFunctions);
console.log("compressors =", caps.cacheCapabilities.supportedCompressors);
```

## Expected output

```text
max_batch_total_size_bytes = 4194304
digest functions = [ 'SHA256', 'BLAKE3' ]
compressors = [ 'IDENTITY', 'ZSTD' ]
```
