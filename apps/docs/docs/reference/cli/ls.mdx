# `corelink ls`

List CAS / Action Cache entries for a tenant.

## Synopsis

```bash
corelink ls --tenant <TENANT_ID> [--prefix <PREFIX>] [--limit <N>] [--cursor <CURSOR>] [--output <FORMAT>]
```

## Flags

| Flag | Required | Default | Description |
|---|---|---|---|
| `--tenant` | yes | — | Tenant ID. |
| `--prefix` | no  | — | Client-side filter: keep only blobs whose hash starts with this prefix (applies to the current page only). Not sent to the server. |
| `--limit`  | no  | `100` | Maximum entries to return per page (1..1000). |
| `--cursor` | no  | — | Pagination cursor from a previous response. |
| `--output` | no  | `text` | `text` or `json`. |

## Examples

List the first 50 CAS entries:

```bash
corelink ls --tenant acme-corp --limit 50
```

Paginate JSON:

```bash
corelink ls --tenant acme-corp --output json
# → { "blobs": [...], "next_cursor": "abc123" }
corelink ls --tenant acme-corp --cursor abc123 --output json
```

Filter a page to a hash prefix (client-side):

```bash
corelink ls --tenant acme-corp --prefix ab --output json
```

## JSON schema

The body is the server's `GET /v1/cas/{tenant}` response verbatim — one
**page** of blobs plus an opaque continuation cursor (`null` on the last
page). There is no total count.

```json
{
  "blobs": [
    {
      "hash": "0123...cdef",
      "size": 1048576,
      "created_at": "2026-05-14T00:00:00Z"
    }
  ],
  "next_cursor": "abc123"
}
```

## Exit codes

`0` success · `1` runtime failure · `2` argument error.
