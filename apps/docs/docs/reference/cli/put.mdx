# `corelink put`

Upload a file. BLAKE3 digest is computed locally unless `--digest` is
supplied.

## Synopsis

```bash
corelink put <FILE> [--digest <DIGEST>] [--output <FORMAT>]
```

## Arguments

| Arg | Required | Description |
|---|---|---|
| `<FILE>` | yes | Path to the file to upload. |

## Flags

| Flag | Required | Default | Description |
|---|---|---|---|
| `--digest` | no | computed | Pre-computed BLAKE3 hex digest. Not checked client-side — uploaded as claimed; the server re-hashes and rejects a wrong claim with `422`, which fails with exit `1`. |
| `--output` | no | `text` | `text` or `json`. |

## Examples

```bash
corelink put ./build/output.tar
# stdout: 64-char hex digest
```

Pre-computed digest:

```bash
DIGEST=$(b3sum ./out.tar | awk '{print $1}')
corelink put ./out.tar --digest "$DIGEST"
```

JSON output:

```bash
corelink put ./out.tar --output json
```

## JSON schema

```json
{
  "ok": true,
  "subcommand": "put",
  "digest": "0123...cdef",
  "size_bytes": 1048576,
  "duplicate": false
}
```

`duplicate=true` means the digest already existed server-side and the
upload short-circuited (CTRL-CAS-001 dedupe).

## Exit codes

The CLI has exactly four exit codes, shared by every subcommand:

| Code | Meaning |
|---|---|
| `0` | Uploaded (or dedup hit). |
| `1` | Any failure — network, auth, quota, digest mismatch (`--digest` wrong), unreadable file. Read the `error: ...` message on stderr for which. |
| `2` | Argument error (for example, malformed flags). |
| `65` | Reserved for `corelink audit verify-ndjson --url` mid-stream abort only — not used by `put`. |
