# `corelink put`

Upload a file. BLAKE3 digest is computed locally unless `--digest` is
supplied.

## Synopsis

```bash
corelink put <FILE> [--digest <DIGEST>] [--output <FORMAT>]
```

## Arguments

| Arg | Required | Description |
|---|---|---|
| `<FILE>` | yes | Path to the file to upload. |

## Flags

| Flag | Required | Default | Description |
|---|---|---|---|
| `--digest` | no | computed | Pre-computed BLAKE3 hex digest. Mismatch fails with exit `3`. |
| `--output` | no | `text` | `text` or `json`. |

## Examples

```bash
corelink put ./build/output.tar
# stdout: 64-char hex digest
```

Pre-computed digest:

```bash
DIGEST=$(b3sum ./out.tar | awk '{print $1}')
corelink put ./out.tar --digest "$DIGEST"
```

JSON output:

```bash
corelink put ./out.tar --output json
```

## JSON schema

```json
{
  "ok": true,
  "subcommand": "put",
  "digest": "0123...cdef",
  "size_bytes": 1048576,
  "duplicate": false
}
```

`duplicate=true` means the digest already existed server-side and the
upload short-circuited (CTRL-CAS-001 dedupe).

## Exit codes

| Code | Meaning |
|---|---|
| `0` | Uploaded (or dedup hit). |
| `1` | Network, auth, or quota failure. |
| `2` | Argument error (e.g. unreadable file). |
| `3` | Digest mismatch (`--digest` wrong). |
| `5` | Rate limit (`COR_QUOTA_RATELIMIT`). |
