# `POST` `/v1/customer/team/accept`

> Redeem a team invitation for the verified Clerk user.

- **Operation ID:** `customerTeamAccept`
- **Tag:** `users`
- **Rate-limit class:** default (600 req/min/PAT)

## Description

Requires the authenticated user's Clerk primary email to be explicitly
marked `verified`. The opaque token is tenant-bound by its stored
digest; no tenant id is accepted from the caller. The expiry check,
audit event and one-row status transition are atomic, so replay fails.
