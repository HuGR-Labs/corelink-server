# `POST` `/v1/onboarding/dpa-accept`

> Record click-through acceptance of the current DPA version.

- **Operation ID:** `dpaAccept`
- **Tag:** `dpa`
- **Rate-limit class:** default (600 req/min/PAT)

## Description

Records the click-through consent proof for the caller's tenant and
returns the immutable audit reference for it. The tenant is taken from
the Clerk-authenticated session at the edge and is **never** read from
the body — a smuggled `tenant_id` is rejected (`400 bad_request`,
unknown fields are denied).

Idempotent on `(tenant, dpa_version)`: replaying an acceptance returns
the original `audit_event_id` unchanged, with the same `200`.

`dpa_version` must equal the server's current DPA version; an older
one is rejected with `400 dpa_version_mismatch`. `dpa_locale` must be
inside the closed GA locale set (`en-US` / `pt-BR` / `es-419`, and
their bare-language forms); anything else — `de` included — is
`400 unsupported_locale`.

`INV-ONBOARD-DPA-FIRST`: `/v1/onboarding/tier-select` stays locked
until an acceptance row exists for the tenant.

## Authentication

- `BearerPAT`
- `ClerkSessionCookie`

## Parameters

_None._

## Request body

- **Media type:** `application/json`
- **Required:** yes
- **Schema:** [`DpaAcceptRequest`](#schema-dpaacceptrequest)

## Responses

| Status | Schema | Description |
| --- | --- | --- |
| `200` | [`DpaAcceptResponse`](#schema-dpaacceptresponse) | Acceptance recorded — or replayed unchanged, which returns the same body as the original acceptance.  |
| `400` | [`DpaAcceptError`](#schema-dpaaccepterror) | `bad_request` (malformed JSON, unknown field, malformed notice hash), `unsupported_locale`, or `dpa_version_mismatch`.  |
| `401` | [`DpaAcceptError`](#schema-dpaaccepterror) | `unauthenticated` (edge internal-auth failed) or `no_verified_tenant` (no tenant bound to the session).  |
| `500` | [`DpaAcceptError`](#schema-dpaaccepterror) | `internal` — durable-store or receipt-signing failure. Fail-CLOSED: never reported as "already accepted".  |
