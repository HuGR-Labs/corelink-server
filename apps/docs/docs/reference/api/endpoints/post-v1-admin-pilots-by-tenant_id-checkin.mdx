# `POST` `/v1/admin/pilots/{tenant_id}/checkin`

> Run the 24-hour activation check-in.

- **Operation ID:** `adminPilotsCheckin`
- **Tag:** `admin-pilot`
- **Rate-limit class:** default (600 req/min/PAT)

## Description

Replaces the wave-27 `pilot-24h-checkin.sh` shell script.
Emits an alert audit row when the tenant has not uploaded a single
blob 24h after `tier_granted_at_ms`.
