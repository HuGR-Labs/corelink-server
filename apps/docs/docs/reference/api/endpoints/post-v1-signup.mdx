# `POST` `/v1/signup`

> Provision a new tenant from a verified Clerk identity.

- **Operation ID:** `signup`
- **Tag:** `signup`
- **Rate-limit class:** anonymous-strict (5 req/min/IP)

## Description

Idempotent signup orchestration. The orchestrator wraps tenant row +
DPA acceptance row + first PAT issuance in a single atomic D1
transaction (`INV-ONBOARD-ATOMIC-PROVISIONING`). Stripe customer
creation is a best-effort saga step — Stripe outage degrades to
`Deferred` with `billing_intent="deferred"`; the tenant is still
provisioned and signed up.

Request body intentionally has **no PAT field** (`CTRL-CRED-001`);
the first PAT is returned in the response (shown-once token).

## Authentication

- `BearerPAT`
- `ClerkSessionCookie`
