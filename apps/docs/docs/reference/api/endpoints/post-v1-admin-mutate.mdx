# `POST` `/v1/admin/mutate`

> Admin-plane mutate (dual-approval-gated).

- **Operation ID:** `adminMutate`
- **Tag:** `admin-read-mutate`
- **Rate-limit class:** default (600 req/min/PAT)

## Description

`AdminMutateHandler` enforces (1) RBAC (initiator must hold admin
role), (2) dual-approval token presence, (3) approver ≠ initiator.
Each path emits the corresponding `MutateAttempted` /
`MutateDenied` / `MutateDualApprovalRejected` audit row BEFORE
the response (audit-emit-BEFORE-handler atomicity).
