# `POST` `/v1/pats`

> Issue a new Personal Access Token.

- **Operation ID:** `patIssue`
- **Tag:** `pat`
- **Rate-limit class:** pat-issue (10 req/hour/tenant)

## Description

Returns the raw token material **once** (`shown_once`). The token is
hashed (BLAKE3-keyed) before storage; subsequent reads only ever
return the hash prefix and metadata.

## Authentication

- `BearerPAT`
- `ClerkSessionCookie`

## Parameters

_None._

- **Media type:** `application/json`
- **Required:** yes
