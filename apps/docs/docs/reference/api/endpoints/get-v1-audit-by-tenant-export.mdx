# `GET` `/v1/audit/{tenant}/export`

> Stream a bulk audit-chain export from R2.

- **Operation ID:** `auditExport`
- **Tag:** `audit-export`
- **Rate-limit class:** default (600 req/min/PAT)

## Description

Streams the per-tenant audit chain over the supplied `[from, to)`
window. Window bounds accept either ISO 8601 UTC
(`YYYY-MM-DDTHH:MM:SSZ`) or raw Unix epoch milliseconds. Cross-
tenant attempts emit a security audit row BEFORE the 403.

## Authentication

- `BearerPAT` (scopes: `admin`)

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `from` | `query` | yes | `string` | Inclusive lower bound (ISO 8601 UTC or Unix ms). |
| `to` | `query` | yes | `string` | Exclusive upper bound (same shapes as `from`). |
| `tenant` | `path` | yes | `string <uuid>` | The tenant whose chain is exported. When it differs from the authenticated principal's tenant, the route emits a cross-tenant attempt audit row and returns 403.  |
| `X-Tenant-Id` | `header` | no | `string <uuid>` |  |

## Request body

_No request body._

## Responses

| Status | Schema | Description |
| --- | --- | --- |
| `200` | `string` | NDJSON stream of audit events. |
| `401` | [`ErrorEnvelope`](#schema-errorenvelope) | Missing or invalid credentials. |
| `403` | [`ErrorEnvelope`](#schema-errorenvelope) | Cross-tenant attempt or canceled tenant. |
| `429` | _(empty body)_ | Per-tenant rate limit exceeded. |
