# `POST` `/v1/customer/account/delete`

> Request deletion of the authenticated tenant account.

- **Operation ID:** `customerAccountDelete`
- **Tag:** `privacy-dsr`
- **Rate-limit class:** privacy-strict (10 req/hour/subject)

## Description

Requests GDPR/LGPD erasure of the caller's whole tenant account. This
irreversible operation is restricted to the tenant owner using a
Clerk-authenticated dashboard session; a cache PAT is rejected.

The request is durably anchored and queued before acknowledgement. A
repeated request is safe and returns the same accepted outcome. The
response does not claim that erasure has completed: it only confirms
that the erasure workflow was accepted (`erasure_requested`) or that
no account remained (`no_account`).
