# `POST` `/v1/signup/pilot/{token}`

> Redeem an HMAC-signed pilot signup token.

- **Operation ID:** `pilotSignup`
- **Tag:** `signup-pilot`
- **Rate-limit class:** default (600 req/min/PAT)

## Description

Server-only route (axum-mounted). Token format
`pilot_<env>_<unix_ms>_<16-hex-random>.<hmac-hex>` verified in
constant time via `subtle::ConstantTimeEq`. TTL 14 days from mint.
Rate-limited 5/IP/hour. Audit-emit fail-CLOSED per
`INV-AUDIT-EMIT-ATOMIC-WITH-HANDLER`.

## Authentication

_Public — no authentication required._
