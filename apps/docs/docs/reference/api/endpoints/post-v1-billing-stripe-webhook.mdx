# `POST` `/v1/billing/stripe-webhook`

> Receive a Stripe webhook event (HMAC-SHA256 signature required).

- **Operation ID:** `stripeWebhook`
- **Tag:** `billing`
- **Rate-limit class:** webhook-source (Stripe signature gated; not user-metered)

## Description

Implemented at `apps/server::webhook::stripe_webhook_handler`.
Validates the `Stripe-Signature` header (5-minute replay window),
deduplicates on `event.id`, then dispatches to the subscription
handler. Unknown / out-of-scope event types are acknowledged with
200 OK (fire-and-forget contract).

**NOT secured by BearerPAT / Clerk** — see `StripeSignature` scheme.

## Authentication

- `StripeSignature`

## Parameters

| Name | In | Required | Type | Description |
| --- | --- | --- | --- | --- |
| `Stripe-Signature` | `header` | yes | `string` | Stripe HMAC-SHA256 signature header (`t=&lt;unix&gt;,v1=&lt;sig&gt;`). |

## Request body

- **Media type:** `application/json`
- **Required:** yes
- **Schema:** [`StripeWebhookEnvelope`](#schema-stripewebhookenvelope)

## Responses

| Status | Schema | Description |
| --- | --- | --- |
| `200` | `string` | Event accepted (including idempotent replays and acknowledged unknown event types). |
| `400` | `string` | Missing or invalid signature, or malformed event body. |
| `500` | `string` | Transient backend error; Stripe will retry. |
