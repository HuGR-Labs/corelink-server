# `POST` `/v1/customer/account/export`

> Export the authenticated tenant's portability bundle.

- **Operation ID:** `customerAccountExport`
- **Tag:** `privacy-dsr`
- **Rate-limit class:** privacy-strict (10 req/hour/subject)

## Description

Streams the complete tenant portability bundle as bounded,
content-addressed NDJSON: governance records first, then CAS/AC blob
bytes, followed by a manifest. Only an owner/admin with a dashboard
session or a write-capable PAT may invoke it; read-only cache tokens are
rejected because the bundle contains team PII, DPA/audit records and
all tenant blobs.

The export is rate-limited and an audit record is durably written before
the first byte is disclosed. A source or audit failure returns a 5xx
before streaming begins; the `x-corelink-export-schema` header is
`corelink.tenant_export.v1`.
