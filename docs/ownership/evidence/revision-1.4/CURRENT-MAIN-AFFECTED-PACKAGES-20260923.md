Therefore the impact is not confined to the nine manifests above: every workspace-member artifact that states an inherited package version, a local lock-node version, or the old `corelink-hash` version edge needs a targeted manifest/lock readback and `STALE` marker until reconciled. This does not by itself invalidate unrelated package implementation analysis or the 105-package identity census.

Recommended batch action: run one current-main metadata reconciliation across all workspace members against root `Cargo.toml` and `Cargo.lock`; update only artifacts with affected version/lock claims. Do not trigger full implementation rereads for packages with no package-local source or manifest drift.
