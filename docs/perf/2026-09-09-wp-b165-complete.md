## Measurement contract repair (B-364)

The former 15–30 ms comparison mixed client-to-colo transport with service
processing. That is not a defensible service SLI: in this capture, the health
control median alone was 47.877 ms. The corrected instrument records two clocks
without subtracting unrelated population medians:

- `Server-Timing: total;dur=` is the primary per-request service-side clock;
- `curl_total_ms - server_total_ms` is the same request's transport residual.

The verifier requires a one-to-one sample identity, checks the arithmetic and
rejects missing/impossible server timing. This avoids both geographic RTT bias
and statistically invalid subtraction of independent medians. The authoritative
CAS GET SLO remains the edge-measured 30-day p99 contract (team <300 ms,
enterprise <200 ms); this ten-sample p90 receipt is diagnostic evidence only and
does not assert a 30-day SLO verdict.

## Padding decision

HTTP 401 is **not padded**. It returns before tenant/object lookup, so it cannot
reveal object existence; deliberate delay would only create an unauthenticated
latency/amplification primitive. Authenticated 404 misses remain padded under
ADR-0023 because their internal miss arms can reveal cross-tenant existence by
timing. The verifier proves the executable boundary: `index_auth_stage.ts`
contains the 401 return and no padding call, while both supported 404 paths keep
their `applyTimingPad` call. Mutation tests fail if padding is added to the auth
stage or removed from the forwarded 404 boundary. No 200/403/413/429/5xx policy
was changed.
