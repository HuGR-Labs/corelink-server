Every WP inherits the following unless a row says otherwise:

- **Read first:** `CLAUDE.md`; `BACKLOG.md` and the item's complete body;
  `docs/internal/DELEGATION-WP-CONTRACT.md`; the relevant Part VI contract in
  `docs/campaigns/remediation/ROADMAP.md`; the named harness, source of truth,
  and gates in the WP row. Read the contract of each seam, not just the file.
- **Axiom:** execution is delegated; judgment is not. Do only the decided
  change and stop on an unlisted decision.
- **Invariants:** no silent fail-open, no comment/prose satisfying a code
  predicate, no empty/truncated population being treated as clean, and no
  secret or customer credential in source, arguments, logs, fixtures, or
  reports.
- **Quality:** no new dependency, no incidental reformat, no unlisted export,
  strict TypeScript/Rust checks where applicable, deterministic fixtures, and
  tests assert outcomes/counts rather than wall-clock timing.
- **Completeness:** every population named in the row is inspected; absence of
  an instrument, parse failure, missing control, or truncated API response is
  a distinct high failure, never a green result.
- **Lead DoD:** line-by-line diff review; citations and paths verified; suite
  green; fix reverted while the new test goes red for the stated reason;
  `[Unreleased]`/DCO/secrets/OKF checks; final rebase and
  `bash scripts/pre-merge-gate-check.sh --merge <PR>`.
- **Return card:** changed files, unchanged files checked, evidence commands
  and outputs, unresolved decisions/blockers, proposed PR/base, and explicit
  statement of what was not done. A delegate must not claim to have run tests;
  the lead runs them.

The following entries are intentionally grouped only where they share a file
