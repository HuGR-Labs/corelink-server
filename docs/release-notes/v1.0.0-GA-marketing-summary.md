## The headline (one sentence)

**CoreLink is a shared, content-addressable cache for builds, packages,
Docker images, and ML artefacts — one cache, every consumer, end-to-end
cryptographically verifiable — and v1.0.0 GA is now production-ready.**

## The 30-second pitch

Every engineer rebuilds the same artefact. Every CI runner re-downloads
the same image. Every model retraining re-fetches the same dataset.
CoreLink stores each one **once**, by **content hash**, and serves it
back to everyone who asks — Bazel, Buck2, Cargo, Gradle, Docker, Python
wheels, model checkpoints — over the same **REAPI v2** wire your build
system already speaks.

Drop in the URL. Keep your build files. Get a cache hit rate that
actually matches your team size.

## Why it matters

- **Build times collapse** when the cache works across engineers,
  CI runners, and production hosts — not just locally.
- **CI bills drop** when artefacts are deduplicated by content, not by
  filename or by namespace.
- **Audit trails become real** when every state-mutating operation is
  Merkle-chained, 7-year retained, and verifiable on an auditor's
  laptop without CoreLink credentials.

## The headline features (six)

1. **REAPI v2 wire** — drop-in compatible with `bazelbuild/remote-apis`
   v2.12.0. Bazel / Buck2 / Cargo / Gradle / Docker / Python wheels /
   ML checkpoints over one protocol.
2. **End-to-end BLAKE3 verification** — server-side at PUT, client-side
   at GET, default-on. No silent corruption.
3. **Tamper-evident audit chain** — CloudEvents 1.0 envelopes, Merkle
   chained, 7-year retained, customer-verifiable offline.
4. **BYOK with sub-6-minute kill switch** — 4 KMS providers, AES-256-GCM
   envelope encryption with CSPRNG-derived DEKs, per-tenant FIPS toggle.
5. **4 production regions** — WNAM, ENAM, WEUR, SAM — with automatic
   read-side failover on region partition.
6. **Privacy + DSR done right** — 6-field cryptographically-pinned
   consent capture, 6 DSR rights with MFA re-auth, Ed25519 erasure
   attestation, GDPR + LGPD + LFPDPPP-aligned.
