# CoreLink SDK Quickstart Examples

Runnable, copy-and-edit-friendly examples for the **top-10 CoreLink REST endpoints**, in **four languages** (Rust / Python / Go / TypeScript). Forty short programs total. Each is self-contained (no shared helpers across files), uses only the language's standard HTTP client plus minimal idiomatic dependencies, and obeys the CoreLink SDK quality charter (`#![forbid(unsafe_code)]` in Rust, no `unwrap`/`expect`, env-var sanity checks, proper error propagation).

> If you're looking for the autogenerated API reference (request/response schemas, status codes, language snippets per endpoint), see [`apps/docs/docs/reference/api/endpoints/`](../apps/docs/docs/reference/api/endpoints/). This `examples/` tree is the *runnable* companion — clone, set env vars, run.

## Sandbox setup

All examples default to the public sandbox at `https://corelink-app.humangr.com/sandbox` when `CORELINK_API_URL` is not set. To run against your own tenant:

```bash
export CORELINK_API_URL="https://corelink-api.humangr.com"     # or your dedicated region URL
export CORELINK_PAT="corelink_pat_..."                  # PAT issued via POST /v1/pats
```

Issue a sandbox PAT through the Console (https://corelink-app.humangr.com/pats) or via the bootstrap signup flow (`quickstart_signup` + `quickstart_put`).

## How to run

### Rust

```bash
CORELINK_PAT=$PAT cargo run --example quickstart_signup -p corelink-cli
CORELINK_PAT=$PAT cargo run --example quickstart_get    -p corelink-cli
# … etc.
```

Build all 10 at once: `cargo build --examples -p corelink-cli`.

### Python (≥3.10)

Examples use only the stdlib (`urllib.request`) so no `pip install` is required:

```bash
CORELINK_PAT=$PAT python3 tools/sdks/python/examples/quickstart_signup.py
```

### Go (≥1.21)

Each `.go` file is marked `//go:build ignore` (canonical Go-stdlib pattern) so the files coexist as runnable single-file programs:

```bash
CORELINK_PAT=$PAT go run tools/sdks/go/examples/quickstart_signup.go
```

### TypeScript (Node ≥18, `tsx` recommended)

Top-level `await` + native `fetch` mean zero runtime deps:

```bash
CORELINK_PAT=$PAT npx tsx crates/corelink-wasm/examples/quickstart_signup.ts
```

## Quality charter

Every example in this tree:

- **Reads config from env** — `CORELINK_API_URL` (defaults to public sandbox) + `CORELINK_PAT` (sanity-checked with an actionable error when missing).
- **Idiomatic per language** — async/await in Rust+TS, blocking `urllib` in Python, channels-less `net/http` in Go.
- **No `unwrap`/`expect`/`panic!`** in Rust; `?` propagation via `anyhow::Result`. `#![forbid(unsafe_code)]` on all Rust examples.
- **Proper error handling** — HTTP error vs network error vs decoding error are distinguished where it adds signal.
- **30–50 lines** — short enough to read top-to-bottom in 30 seconds.
